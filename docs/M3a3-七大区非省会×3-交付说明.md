# M3a3 七大区非省会×3 · 交付说明

日期：2026-09-21  
对照：`docs/M3a2-七大区非省会可玩-交付说明.md`、`docs/提升方向-多维评估报告.md`、PRD §10 M3a。  
原则：**扩面，不是再堆网红城。** 把现有草稿升 live，不足则 `scaffold:city` + 套件再人工补知识/测验。未做重庆展示片，也未把山城崖线写成全国默认皮肤。

## 本切片成功标准

PRD 原文 M3a 写「每省代表城全部 live / 七大区各 ≥3 座非省会 live」。本切片兑现评估报告与 PRD 的 **每区 ≥3 座非省会 live**：

- 七大区 **各 ≥3 座非省会 live**（`isProvincialCapital` = 不是本省行政中心；直辖市 / 自治区首府也不算）
- 全国非省会 live **≥21**
- **不宣称 333 已收录可玩**

石家庄、长春、沈阳、长沙、郑州、广州、贵阳、昆明、乌鲁木齐、兰州等 **不能**拿来充非省会门禁。沈阳、昆明仍是任务点名升 live 的他省省会，不计入 21。

## 工厂路径

1. `npm run scaffold:city -- --adcode=<地级> --kit=<套件>` 导出 B 级草稿（本刀 12 座新城）。
2. `node tools/write-m3a3-packs.mjs` 人工补最低知识/测验、GUARD/VISIT、气候/河海套件，升 live。
3. 青岛、桂林是 M3a2 留下的非省会草稿，本刀直接升 live（青岛改北方砖+海岸带，匹配温带滨海，不再误用江南湿热套件）。

## 质量下限（每座新 live）

- `city.json` / `layout.json` / `knowledge.json` / `quiz.json` 齐
- ≥1 GUARD + ≥1 VISIT；分区 ≥3；知识卡 ≥8；6–8 题 ≥4、9–12 题 ≥5（局后抽 3 题）
- 套件匹配气候/河海：青岛温带滨海用北方砖+海岸带；桂林漓江+岭南骑楼；乐山三江汇合用江南水岸，**不是山城毁城秀**；宝鸡/咸阳关中用北方砖，**不套绿洲卡通**
- 允许 B 级套件剪影，不要求精模
- 唐山抗震纪念碑 = GUARD（重建记忆，不是灾难游戏）；乐山大佛 / 佛山祖庙 / 青岛教堂 = VISIT

## 灰壳规则（不变）

- 34 个省级卡片全部可点。
- 省内列出 live + draft；live 可进 3D，draft 默认「记忆修复中」，可看「预览说明」，**不可开 3D**。
- 不上未审中国全图。客户端禁止 `lat`/`lon`。
- 天安门级 GUARD、宗教/健康/校园 VISIT 继续生效。
- 大厅进度文案写「七大区可玩 / 非省会 live≥21 / 管线」，**不是 333 完成**。

## 门禁

`npm run validate:region7`（别名 `validate:m3a3`）在 M3a2 之上增加：

- 七大区各 ≥3 座 `!isProvincialCapital` 的 live
- 全国非省会 live ≥21
- `M3A3_NONCAPITAL_LIVE` 21 座均在 `liveCityPacks`，且行政上确实不是省会/首府/直辖市

失败即红。`npm run validate` && `npm run build` 必须全绿。

## 明确不做

- 333 / 293 全量 live（那是 M3b）
- 每省代表城全部 live；杭州 / 南京 / 重庆 / 乌鲁木齐标杆加分
- M4 家长账号/后端；家乡 GPS；未审底图
- 把重庆当毁城展示片；把乐山/昆明做成山城毁城秀

## 如何验收

```bash
npm install

```

手工：标题双入口 → 34 省大厅进度条见「非省会 live ≥21」且 **不是 333 完成** → 每区至少抽 1 座本刀新非省会开一局（建议：唐山 / 吉林市 / 青岛 / 开封 / 桂林 / 乐山 / 宝鸡），合计 ≥5 局。点石家庄、长春、长沙、贵阳、乌鲁木齐等草稿只见灰壳/预览，不能进 3D。

## 已知限制

- 地标仍是程序化低模剪影。
- 沈阳是辽宁省会、昆明是云南省会：任务点名升 live，不计入非省会 21。
- 乌鲁木齐仍是绿洲套件草稿，未 live。
- 邻省旅行、四大区域对照卡仍主要出现在题库与图鉴字段。
- **本切片不是 333 完成。**
