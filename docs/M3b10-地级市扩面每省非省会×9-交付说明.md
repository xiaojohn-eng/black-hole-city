# M3b10 地级市扩面 · 每省 ≥9 非省会 live · 交付说明

日期：2026-09-25  
对照：`docs/M3b9-地级市扩面每省非省会×8-交付说明.md`、`docs/提升方向-多维评估报告.md`、PRD §10。  
原则：**凡「非省会 prefecture_city 总数 ≥9」的省/自治区，至少 9 座非行政中心地级市 live。这是 M3b 第九批扩面，不是 293 完成，更不是 333 完成。** 工厂路径：`scaffold:city` + 套件 → `write-m3b10-packs.mjs` 补最低知识/测验。选城按气候/河海多样性与课标常见城，禁止网红插队堆张家界/大理/黄山等山城秀。

## 本切片成功标准

- 凡非省会 `prefecture_city` ≥9 的省/自治区，至少 9 座「非行政中心」地级市 live
  - 行政中心名单以 `tools/region7.mjs` 的 `M3B1_CAPITAL_PACKS` / `isProvincialCapital` 为准
  - 直辖市 / 港澳 / 台湾教学包不要求本刀再加非省会
  - 青海（非省会仅海东 1 座）本刀继续豁免到 ≥9
  - 海南：三沙永不可玩，可玩非省会仅三亚+儋州=2，故按「非省会总数 <9」豁免到 ≥9；勿动三沙
  - 新疆（非省会仅 3 座）无法到 9 → 本刀豁免到 ≥9，但须保持 ≥3
  - 宁夏（非省会仅 4 座）无法到 9 → 本刀豁免到 ≥9，但须保持 ≥4
  - 贵州、西藏（非省会各 5 座）无法到 9 → 本刀豁免到 ≥9，但须保持 ≥5
  - 吉林、云南（非省会各 7 座，已全 live）无法到 9 → 本刀豁免到 ≥9，但须保持 ≥7（不回退 m3b8）
  - 内蒙古、福建（非省会各 8 座，已全 live）无法到 9 → 本刀豁免到 ≥9，但须保持 ≥8（不回退 m3b9）
- M3b9 不回退：非省会 ≥8 的省各 ≥8 座非省会 live（豁免青海、海南、新疆、宁夏、贵州、西藏、吉林、云南与非省会总数 <8 的省）
- M3b8 … M3b1 / M3a3 均不回退
- **不宣称 293 地级市已收录，更不宣称 333 已收录可玩**

本刀新增/升 live **17** 座非省会地级市（15–20 的诚实区间内，上限 22）。结束后 `prefecture_city` live **230/293**。其余地级仍是名录占位。缺口省（M3b9 后仅 8 座非省会 live、且非省会总数 ≥9）各补 1 座。

## 工厂路径

1. 从 CSV / `admin-div-data.mjs` 算出缺口省（M3b9 后仅 8 座非省会 live、且可玩非省会 prefecture_city ≥9 的 17 个省；青海、海南、新疆、宁夏、贵州、西藏、吉林、云南、内蒙古、福建不在缺口内）。
2. `npm run scaffold:city -- --adcode=<缺口城> --kit=<气候/河海套件>` 导出 B 级草稿（本刀 17 座）。
3. `node tools/write-m3b10-packs.mjs` 补知识/测验、GUARD/VISIT、气候/河海套件，升 live，更新 manifest。
4. `npm run validate:m3b10` 断言非省会 ≥9 的省各 ≥9 非省会 live；失败即红。

选城理由（河海多样性，不按网红度）：

- 晋城不选忻州：滹沱河已由石家庄讲过，阳泉桃河也汇入滹沱河；沁河向南入黄河。
- 阜新不选抚顺/辽阳/本溪：浑河在沈阳，太子河在鞍山；本溪水洞不插队。细河补辽西偏干。
- 双鸭山不选伊春：林海不插队。安邦河补松花江支流。
- 宿迁不选常州/镇江：苏南运河已够。骆马湖补苏北的湖。
- 衢州不选丽水：丽水偏山。衢江是钱塘江上游。
- 宣城不选黄山：水阳江向北，新安江留给黄山灰壳。
- 鹰潭不选新余：袁河已在宜春。信江上游在上饶，鹰潭补中下游，不拿龙虎山。
- 菏泽不选聊城/泰安/威海：德州已讲运河，济宁已讲微山湖，泰安是泰山。万福河是入湖之前的平原河。
- 驻马店不选三门峡：汝河是淮河支流，不拿峡谷秀。
- 鄂州不选荆门：长江城已多，梁子湖补「百湖」。
- 娄底不选张家界/怀化：涟水是湘江支流，张家界仍灰壳。
- 河源：韶关已讲北江、肇庆已讲西江，东江是课标三条江里还缺的一条。
- 崇左：左江尚未讲过。玉林是南流江，来宾是红水河。
- 广安不选内江：沱江已在泸州/自贡。渠江是嘉陵江还没讲过的支流（涪江在绵阳）。
- 铜川：陕西非省会只剩这一座，且非省会总数刚好 9。漆水河在秦岭以北。
- 定西不选嘉峪关/金昌：河西绿洲已有酒泉张掖武威。祖厉河向北入黄河，和天水的渭河方向相反。

青海豁免。海南豁免到 ≥9（三沙不可玩）。新疆豁免到 ≥9（非省会仅 3 座，已 live ≥3）。宁夏豁免到 ≥9（非省会仅 4 座，已 live ≥4）。贵州、西藏豁免到 ≥9（非省会各 5 座，已 live ≥5）。吉林、云南豁免到 ≥9（非省会各 7 座且已全 live，保持 ≥7）。内蒙古、福建豁免到 ≥9（非省会各 8 座且已全 live，保持 ≥8）。

## 质量下限（每座新 live）

- `city.json` / `layout.json` / `knowledge.json` / `quiz.json` 齐
- ≥1 GUARD + ≥1 VISIT；分区 ≥3；知识卡 ≥8；6–8 题 ≥4、9–12 题 ≥5（局后抽 3 题）
- 套件匹配气候/河海；允许 B 级套件剪影，不要求精模
- 定西不用绿洲平顶；晋城/阜新/铜川/广安禁止山城毁城秀
- 三沙市保持 `playable_3d=false`，不可拿来充数

## 灰壳规则（不变）

- 34 个省级卡片全部可点，且行政中心可进 3D。
- 省内其余地级：已 live 可进；未做城显示「记忆修复中」，**不可开 3D**。
- 不上未审中国全图。客户端禁止 `lat`/`lon`。
- 天安门级 GUARD、宗教/健康/校园 VISIT 继续生效。
- 大厅进度文案写「34 省行政中心可玩 + 有地级市的省非省会 ≥9/省（豁免青海、海南、新疆、宁夏、贵州、西藏、吉林、云南、内蒙古、福建与非省会总数 <9 的省）/ prefecture 约 230/293 / 管线」，**不是 333 完成，也不是 293 完成。**
