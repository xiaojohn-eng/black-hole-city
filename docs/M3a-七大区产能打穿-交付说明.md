## 本切片成功标准（收缩版 M3a）

PRD 原文 M3a 写「每省代表城全部 live / 七大区各 ≥3 座非省会 live」。本切片按评估报告「产能打穿」收成可验收的工厂切片：

- 七大区 **各 ≥1 座 live 真城**
- 每区管线 **≥3 个名字**（1 live + ≥2 草稿或可玩）
- 全国 live 真城 **≥7**
- 非省会进入 live 或大厅可见草稿 **≥3**
- **不宣称 333 已收录可玩**

## 灰壳规则

- 34 个省级卡片 **全部可点**。
- 省内列出 **live + draft**；live 可进 3D，draft 默认「记忆修复中」，可看「预览说明」，**不可开 3D**。
- 未做城显示「记忆修复中」，不是空白，也不是可进 3D。
- 不上未审中国全图。客户端禁止 `lat`/`lon`。
- 天安门级 GUARD、宗教/健康/校园 VISIT 继续生效。
- 大厅有七大区进度条与筛选芯片。

## 工厂强化

1. `npm run scaffold:city -- --adcode=320500` 从名录 + 套件生成完整目录，并以 `status: draft` 写入/更新 `public/packs/manifest.json`（不进 `liveCityPacks`）。
2. `npm run scaffold:region -- --region=华南` 或 `--all-drafts` 一次拉齐某区/全部灰壳名单。
3. `npm run validate:region7`：缺区、live&lt;7、非省会&lt;3、草稿混进 live 均失败。

## 明确不做

- 333 全量 3D；每省代表城全部 live（留给后续 M3a 扩面）。
- M4 家长账号/后端；家乡 GPS；未审底图。
- 把重庆当默认全国皮肤；把成都做成山城毁城秀。

## 如何验收

```bash
npm install
npm run validate
npm run build
npm run scaffold:city -- --adcode=320100
npm run dev
```

手工：标题双入口 → 34 省大厅 → 七大区筛选 → 广州/武汉/成都/西安各一局（GUARD + VISIT + 局后题）；点苏州等草稿只见灰壳/预览，不能进 3D。

## 已知限制

- 地标仍是程序化低模剪影。
- 西安用北方砖 + 城墙环，未单开「黄土窑洞」套件文件。
- 乌鲁木齐仍是绿洲套件草稿，未 live。
- 邻省旅行、四大区域对照卡仍主要出现在题库与图鉴字段。
