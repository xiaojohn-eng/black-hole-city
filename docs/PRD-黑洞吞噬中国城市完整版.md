## 0. 现网对照：为什么看起来「只有一城 / 重庆感」

| 维度 | 现网 MVP（仓库现状） | 完整版（本文定义的产品） |
| --- | --- | --- |
| 空间对象 | **虚构「星湾市·中央区」** 一块 240×240 程序化网格 | **全国城市内容平台**：34 个省级大厅 + 全量地级行政区可玩包 |
| 地标 | 单一主地标「星湾塔」 | 每城 ≥5 座可识别简化地标，国家级象征建筑走「守护」而非吞噬 |
| 叙事 | 限时冲分、吞建筑，破坏隐喻偏硬 | **清理异常引力、收回城市记忆、馆藏于黑洞博物馆** |
| 学习 | 无图鉴 / 无测验 / 无课标 | 知识卡、图鉴、三学段测验、家长报告 |
| 解锁 | 单图循环 | 黑洞等级 ↔ 可吞噬层级 ↔ 城市 / 省 / 区域解锁 |
| 地理可识别性 | 通用方格路网，风格易被读成「某座山城 / 某座工业城」 | 基于真实轮廓、干线路网、河湖与地标相对布局的**教育向简化** |
| 内容量级 | 1 张图 | 4 直辖市 + 333 地级行政区 + 2 特别行政区 + 台湾省教学包 + 省直辖单元 |

**结论（给研发的一句话）：**  
现网不是「中国城市产品少做了几个城」，而是 **玩法内核已通、内容层仍是虚构单城沙盒**。完整版要把同一套双阈值吞噬，升级为「一城一包、全国可检索」的教育内容平台。重庆只是直辖市之一，**禁止把山城雾都当成全国默认皮肤**。

## 1. 愿景、卖点、用户与学习目标

### 1.1 愿景

让每个孩子都能在 3 分钟的炫酷 3D 局里，把「我的家乡」和「没去过的省」收进同一座博物馆：  
**玩的是地面黑洞成长，学的是中国城市地理、地标、名人、物产与文化符号，养的是版图意识与人地协调观。**

### 1.2 一句话卖点

**操控记忆黑洞，在可识别的中国城市地面上收回散落的城市记忆——从垃圾到地标，从家乡到全国。**

副文案（商店 / 课堂）：  
「不是拆城市，是把被异常引力打散的记忆送回博物馆。34 省都能玩，地级市全覆盖。」

### 1.3 叙事定调（M0 强制，全产品统一）

| 表层玩法 | 儿童向包装 | 禁止表述 |
| --- | --- | --- |
| 移动地面黑洞、吸引、吞噬、成长 | 你是「记忆守护员」。城市出现「异常引力裂隙」，记忆碎片变成可收集物。吸入 = **归档** | 「毁灭真实城市」「攻占」「夷平」 |
| 地标被吸入 | 地标以全息形态进入「黑洞博物馆」展厅，地面恢复平静并留下守护光斑 | 「砸烂某某楼」 |
| 国家象征 / 烈士纪念空间 | **不可吞噬**。改为环绕守护仪式，得到「致敬卡」 | 对天安门、人民英雄纪念碑等做破坏演出 |
| 宗教场所、医院、学校 | 可外观识别；交互为「参观记忆」或低威胁收集，不做崩塌 | 嘲笑信仰、攻击民生设施 |
| 失败 / 超时 | 「裂隙未合拢，记忆暂存口袋，下次再来」 | 「城市被毁」 |

世界观一句：  
**黑洞是便携博物馆的入口，不是末日。**

### 1.4 目标用户

| 角色 | 年龄 / 场景 | 核心诉求 | 产品应答 |
| --- | --- | --- | --- |
| 主玩家 | 6–8 / 9–12 / 13+ | 好看、能变大、家乡能玩 | 三档难度、家乡置顶、炫酷成长 |
| 家长 | 25–45 | 别沉迷、别暴力、最好能学点东西 | 时长锁、学习报告、无强制内购 |
| 教师 / 教研 | 小学道德与法治、初中地理 | 能对课标、能当导入课或课后巩固 | 课标标签、课堂 15 分钟模式 |
| 二次传播 | 亲子短视频、研学机构 | 一眼认出是哪座城 | 轮廓 + 地标剪影可识别 |

**非目标：** 测绘工具、军事沙盘、成人破坏模拟、海外政治舆论文章。

### 1.5 学习目标（课标对齐到可落地层级）

对齐依据：

- 《义务教育地理课程标准（2022 年版）》主题五「认识中国」及地理工具  
- 《义务教育道德与法治课程标准（2022 年版）》国情教育、中华民族共同体意识（小学学段）  
- 小学科学中与天气、地形、资源相关的体验性目标（不作高中自然地理深度）

#### 1.5.1 地理核心素养 → 游戏行为

| 素养 | 游戏内可观察行为 |
| --- | --- |
| 区域认知 | 在全国大厅指出省级位置；进城后能按「河/山/环线」分区移动 |
| 综合思维 | 把气候、物产、建筑材料、玩法变体连成因果（如「干旱绿洲 → 坎儿井收集链」） |
| 人地协调观 | 异常引力来自「记忆失衡」而非征服自然；高原/沙尘/台风是适应而非战胜 |
| 地理实践力 | 读简化地图、辨方向、用图例、完成「家乡调查」家长共玩任务 |

#### 1.5.2 学段落层（必须按题库 `ageBand` 拆开，禁止一套题打天下）

**A. 6–8 岁（小学低中段，对接道德与法治 + 生活经验）**

- 能指认祖国完整版图的「鸡形」示意（合规底图，含台湾岛、海南岛、南海诸岛附图原则）。  
- 知道首都是北京，能认出天安门、故宫等象征（守护，不吞噬）。  
- 能说出自己所在省 / 自治区 / 直辖市 / 特别行政区名称，并在大厅点亮「家乡星」。  
- 能把 3–5 种物产/美食/节庆符号和城市绑定（荔枝—广州，冰灯—哈尔滨）。  
- 能区分「山城 / 水城 / 海城 / 平原城」的直观地形。

**B. 9–12 岁（小学高段 → 初中地理起始，对接「认识中国全貌 / 分区 / 家乡」）**

- 运用中国行政区划图，识别 **34 个省级行政区**，记住简称和行政中心。  
- 说明南海诸岛是中国领土的组成部分，钓鱼岛及其附属岛屿是中国固有领土（**只出现在测验与图鉴文案，不在 3D 战场输出坐标**）。  
- 运用地图说出某城的海陆位置、临省、主要地形与气候带。  
- 理解秦岭—淮河、400 mm 等降水量线、地势阶梯等界线对城市景观的影响。  
- 描述长江、黄河等对沿岸城市生活的影响（防洪、航运、供水）。  
- 归纳民族分布「大杂居、小聚居」，树立中华民族共同体意识（自治州/盟关卡用文化符号而非刻板猎奇）。  
- 说明北京的首都职能（政治、文化、国际交往等，儿童表述）。

**C. 13+ 岁（初中巩固 / 兴趣拓展）**

- 说明自然条件对城市职能与产业的影响（因地制宜）。  
- 描述不同区域差异，理解区域联系（高铁、港口、西气东输等作为「记忆廊道」玩法，不涉及保密设施）。  
- 针对某城的环境问题提出儿童可理解的防护建议（沙尘、内涝、冻害）。  
- 能比较两城：纬度、海陆、地形、气候、作物熟制。  
- 读懂图例、比例尺概念（教育简化，不做测绘精度）。

#### 1.5.3 跨学科（每城内容包必须至少覆盖）

| 学科切口 | 内容字段 | 例子 |
| --- | --- | --- |
| 地理 | `climateBand` `landform` `rivers` `neighbors` | 武汉两江交汇 |
| 历史/名人 | `figures[]` | 西安与丝绸之路、张骞（教学向） |
| 语文/方言文化 | `dialect` `culturalSymbols` | 吴语、粤语、川渝官话的礼貌问候，不做歧视 |
| 科学 | 季节、天气变体 | 台风眼短时静止、冰面摩擦 |
| 美术 | 色彩地理 | 徽派粉墙黛瓦、藏式白墙红窗（尊重，不恶搞） |

## 2. 核心循环与成长曲线

### 2.1 单局核心循环（沿用并升级现网 MVP）

```text
选城（全国大厅 / 省级 / 家乡） 
  → 进入地面 3D 城市场景
  → 移动记忆黑洞（双阈值：半径 + 质量均达标才可归档）
  → 吸引 → 吞噬（归档）→ 质量↑半径↑可吃层级↑
  → 分区推进（生活区 → 产业区 → 地标区）
  → 触发知识卡 / 地标守护或归档
  → 结算：分数 + 博物馆展品 + 测验可选
  → 回大厅点亮图鉴、解锁邻城
```

**现网已验证、完整版必须保留的手感：**

- 双阈值：`playerRadius ≥ sizeThreshold` **且** `playerMass ≥ massThreshold`。  
- 吸引圈 > 吞噬圈；不够大则碰撞阻挡并出锁图标。  
- 质量增加 → 半径增大 → 相机拉远；速度随质量对数下降。  
- 连击窗、地标奖励、限时冲分作为「生涯之外」的一局模式。

**完整版新增闭环（学习正向）：**

```text
归档物体 → 掉落记忆碎片（知识点绑定）
  → 组成知识卡 → 写入城市图鉴
  → 通关或馆藏达标 → 短测验（可跳过，但影响「小博士」星级）
  → 星级决定邻城/省级补给解锁
  → 家长周报展示「本周认识了哪些城」
```

### 2.2 吞噬物层级（全国统一 10 级，城市只换皮肤与特殊物）

沿用现网 L1–L10，完整版把「物」换成城市物产/交通/建筑类型，阈值数值以现网 `TIERS` 为基准，难度档只乘 `thresholdScale`。

| 层级 | 通用名 | 城市替换示例 | 记忆主题 |
| --- | --- | --- | --- |
| L1 | 垃圾 / 碎片 | 落叶、冰碴、荔枝壳、沙粒 | 日常观察 |
| L2 | 路障 / 摊位小品 | 路锥、糖葫芦车、烤馕摊 | 市井 |
| L3 | 小型载具 | 共享单车、三轮、雪橇 | 出行 |
| L4 | 汽车 | 出租车（城市涂装） | 道路 |
| L5 | 公交 / 卡车 | 双层巴士、轮渡、矿卡 | 公共交通 |
| L6 | 小屋 / 传统民居 | 四合院厢房、吊脚楼、窑洞、蒙古包 | 民居地理 |
| L7 | 公寓 / 街区 | 里弄单元、骑楼段 | 城市密度 |
| L8 | 商场 / 场馆 | 体育场、大剧院（外观简化） | 公共文化 |
| L9 | 摩天楼 | 城市天际线代表 | 当代职能 |
| L10 | 地标 | 见各城 `landmarks[]` | 城市身份 |

**特殊层（不占 L1–L10 编号）：**

- `GUARD`：国家象征、烈士空间 → 环绕守护。  
- `VISIT`：学校、医院、宗教外观 → 参观记忆。  
- `ECO`：古树、湿地鸟类剪影 → 生态保护卡，吞噬改为「护送回家」。

### 2.4 城市解锁曲线（全国结构的进度骨架）

```text
M1 三城：北京（首都课）+ 上海（海港课）+ 玩家家乡或成都（内陆对照）
    ↓ 各城「图鉴 40% + 测验 1 次」
M2 省级大厅：34 省全部可点，但省内仅开放行政中心 + 1 个特色城
    ↓ 省会「小博士」≥ 2 星
M3 该省全部地级行政区（市/州/盟/地区）+ 省直辖单元
    ↓ 七大区各点亮 1 个镇馆之宝
M4 区域对照挑战、家长报告、季节全国活动
```

**解锁规则（产品必须写成数据，禁止策划口播）：**

1. **家乡优先：** 首次启动问「你住在哪」，省级 + 地级双写；隐私仅本地存储。  
2. **首都始终可玩：** 北京作为课标强制点，不锁。  
3. **省会门槛：** 生涯等级 ≥3 或任意城 1 次完美局。  
4. **省内全开：** 省会测验正确率 ≥60%（9–12 档；6–8 档改为 3 道图卡配对）。  
5. **跨省：** 相邻省级（拓扑邻接表，见 §3.5）或同地理分区已点亮。  
6. **港澳：** 生涯等级 ≥5，内容包标注「特别行政区」。  
7. **台湾省教学包：** 与省级大厅同等入口，UI 称「台湾省 · 繁体中文教学向城市包」，台北按省级行政中心教学呈现。  
8. **三沙 / 南海相关：** 不进入破坏向 3D 吞噬沙盘；只提供「海洋国土记忆馆」2D/轻 3D 图鉴关（见 §11）。

### 2.5 单城 12–18 分钟学习节奏（课堂可切 15 分钟模式）

| 分钟 | 玩家行为 | 学习投放 |
| --- | --- | --- |
| 0–1 | 鸟瞰轮廓 + 河山位置 | 「我们在哪」知识卡 |
| 1–4 | L1–L4 起步区 | 气候/物产小符号 |
| 4–8 | 民居与交通 | 方言问候、名人 1 |
| 8–12 | 产业或自然变体 | 因地制宜 |
| 12–15 | 地标 / 守护 | 建筑与首都/城市职能 |
| 15–18 | 结算测验 3–5 题 | 课标点打勾 |

限时冲分默认 180 秒（沿用 MVP），**生涯模式不倒计时**，用「裂隙稳定度」代替，避免课堂被钟声打断。

## 3. 全国结构：从省级到全量地级行政区

### 3.1 产品覆盖定义（写进版本验收）

完整版 **必须** 覆盖以下可玩/可检索单元，缺一不可称为「全国城市完整版」：

| 层级 | 数量口径（以国家公开行政区划统计为准，文档锁定 2024 年末量级） | 产品中的形态 |
| --- | --- | --- |
| 省级行政区 | **34**：23 省 + 5 自治区 + 4 直辖市 + 2 特别行政区 | 全国选城大厅节点 |
| 地级行政区 | **333**：293 地级市 + 30 自治州 + 7 地区 + 3 盟 | **一区一内容包**（最低 B/C 级，见 §9） |

### 4.6 剧情节拍结构（强制 4 拍）

1. **裂隙出现：** 本城典型天气或地理现象被夸张成「记忆漏风」。  
2. **市井收集：** L1–L5，教会气候与物产。  
3. **地方课题：** 变体玩法（冰面、两江、骑楼、绿洲）。  
4. **镇馆归档：** 地标守护或归档，博物馆开灯，孩子能用一句话说出「这座城是怎样的」。

| 地形 | 澳门半岛、氹仔、路环，填海连岛 |
| 人口量级 | S～M 下沿（教学按 S/M） |
| 城市职能 | 特别行政区；历史城区、桥梁连岛 |

**著名建筑 ≥5：** 大三巴牌坊（visit，历史层积教学，去殖民炫耀）；妈阁庙（visit）；议事亭前地广场（visit）；澳门旅游塔外观（swallow）；港珠澳大桥落地示意（guard/visit，与香港包互链，不画国境以外）。品牌赌场建筑 **禁止出现**。

**名人 ≥3：** 郑观应（澳门与近代启蒙教学）、港珠澳大桥建设者集体卡、妈祖信仰与航海安全集体卡（文化，非迷信玩法）。

**物产/美食：** 葡式蛋挞去品牌化「澳门蛋挞」、猪肉脯、水蟹、杏仁饼；强调与内地食材联系。

**方言/文化符号：** 繁体中文可选；粤语、普通话；金莲花（**guard**，回归象征）、石子路、三岛桥梁。

**剧情节拍：** 海风把连岛记忆吹断 → 半岛骑楼收集 → 桥上「连起来」→ 金莲花守护。

**玩法变体：** `coastal_reclaim`、`qilou_arcade`、`star_ferry`（短途客轮）改为桥面路径。

**测验：** 特别行政区、不隶属广东、三岛、金莲花、与香港同为省级特区。

**3D：** `mo_ruinas` `mo_a_ma` `mo_lotus_guard` `mo_tower` `mo_bridge_landfall`。

## 6. 玩法系统

### 6.1 双阈值吞噬（完整版仍是手感宪法）

沿用现网：

```text
canSwallow = radius ≥ sizeThreshold * difficultyScale
          AND mass   ≥ massThreshold * difficultyScale
```

完整版扩展：

- **知识加成（可选，13+ 关）：** 答对本区知识卡后，下一只同主题物体 `massThreshold` 临时 -10%，正反馈而非开挂。  
- **守护替代：** `interact=guard` 不走吞噬，改为环绕角度积分。  
- **生态护送：** 把鸟/鱼带到湿地圈，方向与吞噬相反，教「不是什么都该吃进博物馆」。

难度档（沿用 MVP `easy/normal/hard`）：只改 `thresholdScale`、物体密度、视距，不改全国内容。

### 6.2 分区地图

每城 `zones[]` ≥4，沿用 MVP 五分区思想，但 **按地理真实功能改名**：

| 通用槽 | 北京例 | 武汉例 | 乌鲁木齐例 |
| --- | --- | --- | --- |
| 起步 S | 城南公园 | 南岸滩涂 | 河滩防护林 |
| 生活 W | 胡同/社区 | 汉口里分 | 居住绿洲 |
| 产业 E | 科教园区 | 光谷示意 | 高新区 |
| 自然 N | 西山/湿地 | 东湖 | 南山牧场过渡 |
| 地标 L | 中轴 | 黄鹤楼/江关 | 红山/巴扎 |

物体不刷新（沿用 MVP）为 **限时模式** 默认；生涯模式可「记忆回流」轻度刷新 L1–L3，防止空图，但地标只一次。

### 6.3 限时模式 vs 生涯模式

| | 限时冲分 | 生涯博物馆 |
| --- | --- | --- |
| 时长 | 120/180/240 秒 | 裂隙稳定度，可暂停，课堂 15 分钟切关 |
| 目标 | 分数、完美、连击 | 图鉴%、知识卡、测验星 |
| 继承 | 仅最高分 | 生涯等级、图鉴、家乡 |
| 适合 | 现网玩家、课间 | 主产品、亲子、课堂 |

### 6.4 多人 / 协作（可选，M4）

- **不做对抗吞城。**  
- 协作 2 人：一大一小两个黑洞，小的钻胡同，大的归档 L8+。  
- 课堂模式：教师投屏全国大厅，学生各自家乡同步点亮班级图鉴。  
- 语音默认关；文字仅系统表情。防沉迷与实名按 §11。

### 6.5 季节活动（全国日历，不破坏课标）

| 窗口 | 玩法 | 学习 |
| --- | --- | --- |
| 春节 | 回家列车记忆廊道，点亮「春运地理」 | 人口流动、交通枢纽 |
| 清明/春 | 踏青 eco，沙尘关（北方） | 气候 |
| 端午 | 江南/两湖龙舟航线 | 河流 |
| 暑期 | 研学护照：7 天 7 大区各 1 城 | 区域差异 |
| 中秋 | 赏月纬度不同时间（简化） | 地球运动衔接，点到为止 |
| 国庆 | 版图拼图（合规底图） | 34 省 |
| 冬至 | 哈尔滨冰灯、南方无冰对照 | 纬度 |

### 6.6 计分与博物馆能量（完整版双轨）

限时模式沿用 MVP 思路并改文案：

```text
score = massGained
      + objectsEaten × 5
      + landmarkBonus
      + (perfect ? timeLeft × 2 : 0)
      + comboBonus
      + knowledgeBonus   // 答对知识卡 +50～200，封顶防刷
```

生涯模式主货币改为 **博物馆能量 E**，与分数分轨，避免「为刷分不看知识卡」：

```text
E = 归档物记忆值 + 地标镇馆 + 测验正确×权重 − 超时空转惩罚(极小)
城市解锁看 E 与图鉴%，不看限时高分
```

### 6.7 操作与无障碍（儿童向）

| 项 | 规格 |
| --- | --- |
| 移动 | WASD / 方向键 / 左虚拟摇杆（沿用 MVP） |
| 暂停 | P / Esc / HUD |
| 6–8 | 默认开描边、开锁图标、更大摇杆、知识卡自动弹出可「稍后再读」 |
| 色觉 | 分区不只靠颜色，加纹理（水波、斜纹、点） |
| 动效 | 关闭镜头震动的开关保留；癫痫敏感：闪光 ≤3 Hz 建议 |
| 语言 | 简体默认；港澳台包可切繁体；方言语音可关 |

## 7. 教育系统

### 7.1 图鉴（城市博物馆）

三层图鉴，全部可从大厅进入，不强制先打完 3D。

| 层 | 名称 | 条目来源 | 点亮条件 |
| --- | --- | --- | --- |
| 全国 | 省级厅 | 34 省轮廓、简称、行政中心、气候带 | 进入该省或答对省名题 |
| 城市 | 本城厅 | 地标、名人、物产、方言、河山 | 归档/守护/参观对应物，或测验 |
| 对照 | 比较厅 | 两城气候、作物、民居 | 13+ 默认；6–8 隐藏 |

图鉴完成度公式（成功指标用同一口径）：

```text
cityDex% = 0.4×landmarksFound + 0.2×figuresFound
         + 0.2×productsFound + 0.2×quizMastery
provinceDex% = 省内地级包 cityDex 的算术平均（未制作包计 0，逼出 M3 全量）
nationalDex% = 34 省 provinceDex 平均
```

### 7.2 知识卡

| 字段 | 说明 |
| --- | --- |
| `cardId` | 全局唯一 |
| `title` | ≤10 字 |
| `body` | 6–8：40 字；9–12：80 字；13+：120 字，可折叠 |
| `ageBand` | 可多档共用，正文分版 |
| `curriculumTags[]` | 见附录 C |
| `thumb` | 2D 符号，禁止用未授权照片 |
| `voice` | 可选朗读 |

弹出规则：首次归档某主题物体时弹出；同一卡每局最多 1 次；家长可设「局后汇总」。

### 7.3 测验

- 局后 **3～5 题**，可跳过（跳过则本城「小博士」不加星，图鉴仍可点亮）。  
- 错题进「口袋复习」，下次进同城先出 1 道旧题。  
- 题型：四选一、看图选城、听方言选省、排序（河流上下游，13+）、判断（版图题只用标准示意图）。  
- **禁止**把错误选项设计成伤害民族/地域情感的刻板印象。

星级：

| 星 | 条件（9–12 档） |
| --- | --- |
| 1 | 完成一局生涯或限时 |
| 2 | 图鉴 ≥40% 且测验 ≥60% |
| 3 | 图鉴 ≥80% 且测验 ≥80% 且至少 1 个 GUARD/VISIT 完成 |

6–8 档测验改为配对，阈值各降 10 个百分点。

### 7.4 家长报告

每周本地生成（默认可导出 PDF / 图片，不上云除非家长账号明确同意）：

1. 本周游玩时长、天数（对照防沉迷上限）。  
2. 新点亮城市 / 省级。  
3. 测验正确率（分学段）。  
4. 「会讲的一句话」：系统从本周知识卡抽出 3 句，建议家长让孩子复述。  
5. 建议下一城：家乡邻省或课标缺口（如还没接触秦岭—淮河）。  

家长控制台：时长、夜间锁、是否允许协作、是否显示 13+ 近代史条目、繁简体。

### 7.5 年龄段与难度（必须可切换，可被家长锁）

| | 6–8 | 9–12 | 13+ |
| --- | --- | --- | --- |
| 默认时长 | 120s 限时或 10 min 生涯 | 180s / 15 min | 240s / 20 min |
| 阈值 | `thresholdScale=0.85` | 1.0 | 1.1～1.2 |
| 文案 | 短句、拟人 | 课标词汇出现 | 区域联系、人地协调 |
| 近代史/战争 | 默认关 | 轻量 | 可开，纪念馆不进吞噬 |
| 协作 | 亲子推荐 | 可选 | 可选 |
| 对照厅 | 关 | 选开 | 开 |

现网 `easy/normal/hard` 作为年龄段内的操作难度，与学段正交，HUD 要写清「学习年龄」和「操作难度」是两件事。

### 7.6 课堂模式（教师）

- 15 分钟：1 张省会 + 3 题 + 集体点亮。  
- 禁止要求学生实名到校外账号；班级码当天失效。  
- 提供「对照课标」一页纸：本关对应《地理课标 2022》哪条内容要求。

## 8. 技术架构

### 8.1 延续现网栈

| 层 | 技术 | 完整版增量 |
| --- | --- | --- |
| 构建 | Vite + TypeScript | 内容包按 `adcode` 异步加载 |
| 渲染 | Three.js r186+ | 城市场景、LOD、实例化 |
| 玩法 | 现有 `SwallowSystem` / `Player` / `CameraRig` | 抽 `World` 为城市数据驱动 |
| UI | DOM HUD | 全国大厅、图鉴、测验、家长报告 |
| 音频 | WebAudio 程序音 | 分省音色表 + 少量采样 |
| 存档 | `localStorage` `bhc:v1:` | 升 `bhc:v2:`，加图鉴与防沉迷时钟 |
| 部署 | GitHub Pages（MVP） | 完整版需 CDN 分包；Web 与后续 App WebView 同源 |

**原则：** 不重写吞噬手感；把 `World.buildStaticCity()` 的硬编码网格换成 `layout.json` + 风格皮肤。

### 8.2 真实地图数据源（教育简化，非测绘）

| 用途 | 建议源 | 禁止 |
| --- | --- | --- |
| **中国全图 / 省界 / 国界 / 南海诸岛附图** | 自然资源部 **标准地图服务** 审图号底图，或取得审图的简化矢量 | 用 OSM、GeoJSON 民间库、高德/腾讯边界 **直接当国界** |
| 地级轮廓（选城剪影） | 在标准地图派生的 **大幅简化多边形**（顶点预算见下） | 高精度边界当玩法碰撞 |
| 城市内部路网、河流中心线、建筑轮廓 | OpenStreetMap（ODbL，需署名）按城提取主干；Mapshaper 简化 | 把 OSM 的 `boundary=administrative` 国界塞进大厅 |
| 行政区名称与代码 | 民政/国家地名信息库公开名录做 `admin_div.csv` 主数据 | 自造 adcode |
| POI 教学 | 自建白名单，不爬商业地图 POI 库 | 未授权商标、内部平面图 |

坐标与精度：

- 教学图、互联网示意图位置精度不得高于 1:50 万国家基本比例尺地图（公开地图管理相关规定）。完整版 3D 战场使用 **本地相对坐标**，把简化路网拟合到 240～400 单位边长的玩法空间，**不存储、不显示经纬度数字**（家长/教研后台可另存元数据但不进客户端包）。  
- 不输出争议地区坐标；不在客户端打包未公开的控制点。

简化流水线（城内）：

```text
OSM 提取 highway∈{motorway,trunk,primary,secondary,tertiary,residential?}
  → 删内部庭院路
  → Visvalingam / Douglas-Peucker，干线保留拐点，居住支路网格化
  → 河流 polyline 加宽成玩法带
  → 地标人工钉相对位置（「在河哪一侧、距桥几格」）保证可识别
  → 程序化填充建筑，不求每栋真实
```

### 8.3 场景规模与 LOD

| 档 | 同屏三角预算（移动中端） | 策略 |
| --- | --- | --- |
| low | ≤ 80k | 地标 impostor 广告牌 + 盒子建筑，关掉远景河 |
| medium | ≤ 200k | 地标 LOD1 网格，实例化楼块 |
| high | ≤ 500k | 地标 LOD0，水面反射可选 |

LOD 规则：

- 地标：`LOD0` 手工低模（<3k tri）、`LOD1` 剪影（<800）、`LOD2` 广告牌。  
- 填充建筑：`InstancedMesh`，按气候换贴图集（6～8 套全国共用：北方砖、江南瓦、岭南骑楼、盆地灰、绿洲土、高原白）。  
- 吞噬中物体升到独立网格，结束回对象池。  
- 沿用空间哈希（现网 `SpatialHash` cell=12），完整版地图更大时 cell 随 `MAP_SIZE` 线性放大。

相机：沿用俯斜跟拍；进入山城变体时允许高度层切换，但不改成自由飞行（保持地面黑洞身份）。

### 8.4 性能预算（移动端 Web）

| 指标 | 目标（中端机，如 3 年前安卓 + Safari） |
| --- | --- |
| 首城进关 | ≤ 8 s（含最小包） |
| 切城（已缓存） | ≤ 3 s |
| 帧率 | 中档 30 fps 稳；高档 60 尽力 |
| 内存 | iOS Safari ≤ 400 MB 峰值警示 |
| 包体 | 壳 < 3 MB；S 级城 < 8 MB；B 级城 < 2 MB；全国大厅底图 < 1.5 MB |

手段：gltf 压缩（meshopt/draco 二选一，移动端测）、纹理 512/1024、按省分包、首次只下家乡+北京+上海。

### 8.5 内容驱动的运行时

```text
Boot
 → 加载 admin_div.csv 索引（精简 JSON）
 → 全国大厅（2D/轻 3D 挤出轮廓，标准底图）
 → 选城后动态 import(`packs/${adcode}/`)
 → CityWorldFactory(layout.json, palette, landmarks)
 → SwallowSystem（阈值表不变）
 → HUD 知识卡监听归档事件
```

现网 `MAP_SIZE=240` 作为 B 级默认；S 级可 320～400，但物体配额按密度而非绝对数量增长，防止手机过热。

### 8.6 后端（M4 才需要）

M1–M3 可纯前端 + 静态 CDN。M4 若做家长账号/班级：

- 最小后端：内容版本清单、防沉迷时长（若发行网络游戏须接国家实名认证与防沉迷系统）。  
- 学习数据默认本地；同步需同意书。  
- 不做公开排行榜「毁城数」。

## 9. 内容生产管线

目标：以可验收的工业化流程产出 **333 个地级包 + 直辖市区群 + 特区/教学包**，而不是策划手写 14 个样例后停更。

### 9.1 角色

| 角色 | 职责 |
| --- | --- |
| 地理教研 | 课标标签、对错、区域表述 |
| 玩法策划 | 变体选择、分区、配额 |
| 关卡编辑 | `layout.json`、地标钉点 |
| 美术 | 地标 LOD、调色板、民居套件 |
| 文案 | 知识卡、方言问候 |
| 合规 | 地图、商标、民族、未成年人 |
| 程序 | 校验器、导入、版本 |

### 9.2 编辑器（内部工具，可后置于仓库 `tools/city-editor`）

功能最低集：

1. 导入简化路网与河，显示在 Three 顶视。  
2. 刷分区色块、刷物体配额、钉地标。  
3. 预览双阈值（用现网 `canSwallow`）。  
4. 导出 `layout.json` + 校验报告。  
5. 一键跑附录 A schema。

不允许编辑器导出经纬度到客户端包。

### 9.3 单城流水线（B 级标准工时参考：5～8 人日）

```text
1. 取名录    admin_div 行锁定 adcode、简称、邻接
2. 教研草稿  填 city.json 强制字段（模板问卷）
3. 地图简化  OSM 城内干线 + 人工钉 3～5 地标相对位置
4. 变体选择  从附录 B 勾 1～3 个，禁止同省所有城同一变体
5. 美术      3 地标 LOD + 选用全国民居套件
6. 题库      按附录 C 生成初稿 → 教研改
7. 四审      地理 / 文化 / 合规 / 教学
8. 进包      status: draft → review → live，写入 manifest
9. 回归      低档机 30 fps；知识卡无错字；无国境线进战场
```

S 级 15～25 人日；C 级（州盟地区）3～5 人日，把预算给自然肌理与文化符号而非摩天楼。

### 9.4 规模化「生成」什么、不生成什么

**允许半自动：** 气候带、邻省、人口量级、干线路网简化、题库干扰项（错误省会）、民居套件换色。

**禁止纯模型无审核直接 live：** 民族风俗、历史事件、版图题、宗教建筑交互、在世人物、商标外观。

建议工作流：LLM / 模板生成 `draft` → 教研 diff → 人审。生成器提示词必须内嵌本 PRD §1.3 叙事与 §11 合规。

### 9.5 校验器（CI 门禁）

`npm run validate:cities` 应检查：

- 地级行 333 条，`unitType` 计数：市 293、州 30、地区 7、盟 3。  
- 每包强制字段非空；`landmarks` 数量达级别下限。  
- `interact=guard` 列表包含该城若有的国家象征。  
- 题库 `ageBand` 数量；正确答案唯一；版图题 `needsStandardMap=true`。  
- 客户端包内无 `lat`/`lon` 字段。  
- 广东省包不含港澳节点；台湾包无首都符号。

### 9.6 审核与版本

| 项 | 规则 |

**目标：** 全团队统一「博物馆黑洞」；全国表可机器校验。

## 11. 风险与合规

只给原则与产品落点，**不给争议边界坐标、不给可复制的问题地图。**

### 11.1 地图与版图

必须遵守《公开地图内容表示规范》及标准地图相关要求（以主管部门现行文本为准），产品侧写成：

1. **中国全图** 完整表达领土：大陆、海南岛、台湾岛、南海诸岛、钓鱼岛及其附属岛屿等重要岛屿；南海诸岛以附图表示时，主图南边绘出海南岛最南端。  
2. **台湾** 按省表示；分国设色与大陆同色；不用国名字体、首都符号；台北作省级行政中心教学点。  
3. **香港、澳门** 按省级特别行政区，全称注记；不并入广东省包；广东专题须能表达东沙群岛且图例不得压盖。  
4. **不得** 漏绘、错绘国界与重要岛屿；不得用 OSM/商业地图国界替代标准画法。  
5. 示意图、教学图、互联网登载地图注意公开地图精度与审核要求；上架前走地图审核（如适用）。  
6. 客户端 3D **战场不出现国境线网格**；版图教育放 2D 图鉴与测验。  
7. 本文及资源仓库 **禁止** 提交争议地区坐标、未公布测绘成果、高精度边境数据。

### 11.2 破坏隐喻与未成年人

| 风险 | 落点 |
| --- | --- |
| 宣扬破坏真实城市 | 叙事为归档/守护；结算禁止「摧毁度」 |
| 国家象征被亵渎 | GUARD 名单强制，CI 检查 |
| 暴力、恐怖 | 无血液、无 Screamer；吞噬为卡通吸入 |
| 战争与灾难 | 纪念馆 13+ 图鉴；不模拟轰炸 |
| 防沉迷 | 若属网络游戏：按国家新闻出版署「830」等现行规定实名、时段、时长、充值；本产品 **默认无充值、无抽卡、无随机付费** |
| 沉迷设计 | 禁止限时强逼、禁止隔夜烂尾惩罚；生涯随时暂停 |
| 隐私 | 家乡仅本地；儿童信息不上传；家长报告默认本地 |
| 社交 | 默认关语音；协作需家长开关 |

教育游戏仍可能被认定为网络出版物/游戏，发行前法务定性，不因「教育」自我豁免。

### 11.3 真实地名、商标、肖像

- 地名用法定名称；别称可搜不可替代法定名。  
- 建筑外观用原创低模「可识别简化」，不复制受保护的艺术展览内部、品牌乐园、商业综合体商标造型。  
- 在世人物：优先集体卡；个人须宣传口径安全 + 肖像策略（剪影）。  
- 食品连锁、冰雪大世界、迪士尼等 **默认不出现**。

### 11.4 民族、宗教、地方情感

- 自治州/盟/地区与地级市 **同等尊重、同等内容规格**，不是「加分奇观关」。  
- 文案强调中华民族共同体；服饰、节庆请文化审，禁止猎奇、禁止把习俗做成减益 Debuff。  
- 宗教建筑 VISIT，不嘲讽、不摧毁。  
- 不嘲笑方言；方言语音请本地审听。

### 11.5 三沙与海洋国土

- 三沙市 **不做吞噬沙盘**。  
- 「海洋国土记忆馆」：岛礁标准名称教学、南海诸岛是中国领土、钓鱼岛及其附属岛屿是中国固有领土。  
- 不展示军事部署、不输出地理坐标、不鼓励「占领玩法」。

### 11.6 数据许可

- OSM：遵守 ODbL 署名与 share-alike 对衍生数据的要求；大厅国界不用 OSM。  
- 标准地图：按服务协议与审图号使用。  
- 课标条目可引用条款精神做标签，不整本复制课标文本进游戏。
