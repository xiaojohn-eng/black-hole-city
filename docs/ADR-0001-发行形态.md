# ADR-0001 发行形态（M1）

- 状态：已采纳
- 日期：2026-09-20

## 决定

本阶段发行形态 = **开源网页试玩 / 演示（形态 A）**。

- 不宣称「全国地级已收录」或「333 城可玩」。
- 大厅用 34 省卡片 + 搜索，**不上未审中国全图**，暂缓审图。
- 可玩 3D 仅：虚构训练场·星湾、记忆博物馆·北京。
- 无账号、无付费、无抽卡；图鉴与学段仅存浏览器本地。
- 一旦改为小游戏商店或 App，须重开义务表（版号、实名防沉迷、审图）。

## 后果

333 地级行以 `data/admin_div.csv` 占位门禁存在，`status=placeholder`。`playable_3d=true` 目前仅 `110100` 北京主城。
