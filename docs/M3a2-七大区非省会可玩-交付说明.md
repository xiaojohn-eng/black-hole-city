# M3a2 七大区非省会可玩 · 交付说明

日期：2026-09-21  
对照：`docs/M3a-七大区产能打穿-交付说明.md`、`docs/提升方向-多维评估报告.md`、PRD §10 M3a。  
原则：**把草稿升 live，不是再堆网红城。** 未做重庆展示片，也未把山城崖线写成全国默认皮肤。

## 本切片成功标准（收缩版 M3a2）

PRD 原文 M3a 写「每省代表城全部 live / 七大区各 ≥3 座非省会 live」。本切片按评估报告「非省会占比是 M3 指标」收成可验收的工厂切片：

- 七大区 **各 ≥1 座非省会 live**（`isProvincialCapital` = 不是本省行政中心）
- 全国非省会 live **≥7**
- 任务点名的 7 座（保定、沈阳、苏州、洛阳、深圳、昆明、酒泉）均 live
- **不宣称 333 已收录可玩**

## 口径说明（沈阳 / 昆明）

任务点名「东北：沈阳优先」「西南：昆明或贵阳」。这两座**是他省省会**（沈阳=辽宁省行政中心，昆明=云南省行政中心），不能单独撑起「各区 ≥1 非省会」门禁。

因此本切片：

1. **按任务点名**把现有草稿升 live：保定、沈阳、苏州、洛阳、深圳、昆明、酒泉。
2. **用工厂补真正的非省会**：`scaffold` 口径的大连（东北）、遵义（西南），再人工补知识/测验后升 live。

乌鲁木齐仍是自治区首府草稿；西北非省会用酒泉。未做杭州 / 南京 / 重庆标杆加分（重庆禁止山城毁城秀，本刀不碰）。

## 质量下限（每座新 live）

- `city.json` / `layout.json` / `knowledge.json` / `quiz.json` 齐
- ≥1 GUARD + ≥1 VISIT；分区 ≥3；知识卡 ≥8；6–8 题 ≥4、9–12 题 ≥5（局后抽 3 题）
- 套件匹配气候/河海：洛阳改北方砖（温带）+ 洛河带；酒泉绿洲平顶；深圳岭南骑楼（无世界之窗/迪士尼）
- 允许 B 级套件剪影，不要求精模
- 遵义会议会址 = VISIT 文保；红军烈士纪念碑 = GUARD。博物馆叙事，不是战争游戏

## 灰壳规则（不变）

- 34 个省级卡片全部可点。
- 省内列出 live + draft；live 可进 3D，draft 默认「记忆修复中」，可看「预览说明」，**不可开 3D**。
- 不上未审中国全图。客户端禁止 `lat`/`lon`。
- 天安门级 GUARD、宗教/健康/校园 VISIT 继续生效。
- 大厅进度文案写「七大区可玩 / 非省会 live / 管线」，**不是 333 完成**。

## 门禁

`npm run validate:region7` 在 M3a 覆盖之上增加：

- 七大区各 ≥1 座 `!isProvincialCapital` 的 live
- 全国非省会 live ≥7
- 任务点名 7 座均在 `liveCityPacks`

失败即红。`npm run validate` && `npm run build` 必须全绿。

## 明确不做

- 333 / 293 全量 live（那是 M3b）
- 每省代表城全部 live；杭州 / 南京 / 重庆 / 乌鲁木齐标杆加分
- M4 家长账号/后端；家乡 GPS；未审底图
- 把重庆当毁城展示片；把昆明/遵义做成山城毁城秀

## 如何验收

```bash
npm install
npm run validate
npm run build
npm run dev
```

手工：标题双入口 → 34 省大厅 → 七大区芯片可见「非省会」→ 至少抽 保定 / 苏州 / 洛阳（或大连、深圳、酒泉）各一局（GUARD + VISIT + 局后 3 题）。点青岛、桂林、乌鲁木齐等草稿只见灰壳/预览，不能进 3D。

## 已知限制

- 地标仍是程序化低模剪影。
- 沈阳是辽宁省会、昆明是云南省会：任务点名升 live，真正的东北/西南非省会是大连、遵义。
- 乌鲁木齐仍是绿洲套件草稿，未 live。
- 青岛、桂林仍是非省会草稿，留给后续扩面（目标仍是每区 ≥3 非省会）。
- 邻省旅行、四大区域对照卡仍主要出现在题库与图鉴字段。
