# M3b8 地级市扩面 · 每省 ≥7 非省会 live · 交付说明

日期：2026-09-22  
对照：`docs/M3b7-地级市扩面每省非省会×6-交付说明.md`、`docs/提升方向-多维评估报告.md`、PRD §10。  
原则：**凡「非省会 prefecture_city 总数 ≥7」的省/自治区，至少 7 座非行政中心地级市 live。这是 M3b 第七批扩面，不是 293 完成，更不是 333 完成。** 工厂路径：`scaffold:city` + 套件 → `write-m3b8-packs.mjs` 补最低知识/测验。选城按气候/河海多样性与课标常见城，禁止网红插队堆张家界/大理/黄山等山城秀。

## 本切片成功标准

- 凡非省会 `prefecture_city` ≥7 的省/自治区，至少 7 座「非行政中心」地级市 live
  - 行政中心名单以 `tools/region7.mjs` 的 `M3B1_CAPITAL_PACKS` / `isProvincialCapital` 为准
  - 直辖市 / 港澳 / 台湾教学包不要求本刀再加非省会
  - 青海（非省会仅海东 1 座）本刀继续豁免到 ≥7
  - 海南：三沙永不可玩，可玩非省会仅三亚+儋州=2，故按「非省会总数 <7」豁免到 ≥7；勿动三沙
  - 新疆（非省会仅 3 座：克拉玛依/吐鲁番/哈密）无法到 7 → 本刀豁免到 ≥7，但须保持 ≥3（即 M3b4 不回退）
  - 宁夏（非省会仅 4 座）无法到 7 → 本刀豁免到 ≥7，但须保持 ≥4（即 M3b5 不回退）
  - 贵州、西藏（非省会各 5 座）无法到 7 → 本刀豁免到 ≥7，但须保持 ≥5（即 M3b6 不回退）
- M3b7 不回退：非省会 ≥6 的省各 ≥6 座非省会 live（豁免青海、海南、新疆、宁夏与非省会总数 <6 的省）
- M3b6 不回退：非省会 ≥5 的省各 ≥5 座非省会 live
- M3b5 / M3b4 / M3b3 / M3b2 / M3b1 / M3a3 均不回退
- **不宣称 293 地级市已收录，更不宣称 333 已收录可玩**

本刀新增/升 live **21** 座非省会地级市（18–28 的诚实上限内，上限 30）。结束后 `prefecture_city` live **194/293**。其余地级仍是名录占位。缺口省（M3b7 后仅 6 座非省会 live、且非省会总数 ≥7）各补 1 座。

## 工厂路径

1. 从 CSV / `admin-div-data.mjs` 算出缺口省（M3b7 后仅 6 座非省会 live、且可玩非省会 prefecture_city ≥7 的 21 个省/自治区；青海、海南、新疆、宁夏、贵州、西藏不在缺口内）。
2. `npm run scaffold:city -- --adcode=<缺口城> --kit=<气候/河海套件>` 导出 B 级草稿（本刀 21 座）。
3. `node tools/write-m3b8-packs.mjs` 补知识/测验、GUARD/VISIT、气候/河海套件，升 live，更新 manifest。
4. `npm run validate:m3b8` 断言非省会 ≥7 的省各 ≥7 非省会 live；失败即红。

## 质量下限（每座新 live）

- `city.json` / `layout.json` / `knowledge.json` / `quiz.json` 齐
- ≥1 GUARD + ≥1 VISIT；分区 ≥3；知识卡 ≥8；6–8 题 ≥4、9–12 题 ≥5（局后抽 3 题）
- 套件匹配气候/河海；允许 B 级套件剪影，不要求精模
- 呼伦贝尔不用毡房默认皮；吕梁/白山/黄石/攀枝花/丽江/安康禁止山城毁城秀
- 三沙市保持 `playable_3d=false`，不可拿来充数

## 灰壳规则（不变）

- 34 个省级卡片全部可点，且行政中心可进 3D。
- 省内其余地级：已 live 可进；未做城显示「记忆修复中」，**不可开 3D**。
- 不上未审中国全图。客户端禁止 `lat`/`lon`。
- 天安门级 GUARD、宗教/健康/校园 VISIT 继续生效。
- 大厅进度文案写「34 省行政中心可玩 + 有地级市的省非省会 ≥7/省（豁免青海、海南、新疆、宁夏、贵州、西藏与非省会总数 <7 的省）/ prefecture 约 194/293 / 管线」，**不是 333 完成，也不是 293 完成。**

## 门禁

`npm run validate:m3b8`：

- 非省会 prefecture_city ≥7 的省/自治区各 ≥7 座非省会 live（计分母时排除三沙；adcode 与 `data/admin_div.csv` 对齐）
- 青海豁免（仅海东 1 座非省会地级市，且海东仍 live）
- 海南豁免到 ≥7：可玩非省会保持三亚+儋州；三沙仍不可玩
- 新疆豁免到 ≥7：非省会仅 3 座且保持 ≥3 live
- 宁夏豁免到 ≥7：非省会仅 4 座且保持 ≥4 live
- 贵州、西藏豁免到 ≥7：非省会各 5 座且保持 ≥5 live
- 本刀 21 座新 live 均在 `liveCityPacks`，且都不是行政中心，也不在豁免省
- `prefecture_city` live 在 191–203（诚实上限：本刀不是 293 完成）
- disclaimer 必须写 ≥7、豁免青海、海南/三沙、新疆、宁夏、贵州、西藏、非省会总数 <7、约 194/293、不是 333、不是 293，并保留 34 省行政中心与非省会 ≥21
- 三沙不可玩；新包不得使用 `mountain_layers` 默认皮
- 张家界、黄山、大理保持灰壳
- 丽江若 live，知识卡必须讲金沙江，并写明不是网红、不是山城毁城秀
- 白山若 live，知识卡必须讲浑江，并写明不拿长白山插队

`npm run validate:m3b7` 继续断言非省会 ≥6。原切片上限 182 放宽为仍禁止 ≥293：≥6 地板不回退，否则本刀 194 座会把上一道门禁打红。  
`npm run validate:m3b6` … `validate:m3b1` 与 `npm run validate:region7`（别名 `validate:m3a3`）继续生效。失败即红。

`npm run validate` && `npm run build` 必须全绿。

## 已知限制

- 地标仍是程序化低模剪影。
- 呼伦贝尔用北方砖认冷草原上的湖，不用毡房。
- 攀枝花的气候卡写干热河谷；套件用水岸剪影认金沙江，不套河西绿洲。
- 宿州 packId 为 `suzhouah`，避免与苏州 `suzhou` 冲突。
- 丽江、白山是该省最后一座未 live 的地级市，用来打穿 ≥7，不是网红插队。
