## 灰壳规则

- 34 个省级卡片 **全部可点**。
- 省内只开放 **行政中心 + 本切片已做代表城**。
- 未做城显示「记忆修复中」，不是空白，也不是可进 3D。
- 不上未审中国全图。客户端禁止 `lat`/`lon`。
- 港澳台：入口文案与简称题在公共题库，3D 包未做。

## 做了什么

1. **34 省简称公共题库 live：** `public/packs/_shared/province-abbr-quiz.json`。大厅可抽 3 题；真城局后测验混入省级题。`npm run validate:province-quiz` 保证 34 省都有简称题。
2. **套件 0 号：** `data/kits/` 四方——北方砖+胡同、江南水岸、岭南骑楼、绿洲平顶。导出步骤见该目录 README。
3. **省会 A 级扩展：** 上海（江南水岸 + 江海）与哈尔滨（北方砖冷色 + 冰雪江岸）。每城 city/layout/knowledge/quiz 最低集，含 GUARD + VISIT。
4. **省级大厅：** 可点 34 省；有 live 城的省显示「可玩 · N 座」。
5. **编辑器 v0.1：** `npm run scaffold:city -- --adcode=320100` 从名录+套件生成 **非 live** B 级草稿目录。
6. 校验扩展：`validate:packs` 覆盖三座真城；新增 kits / province-quiz。

## 如何验收

```bash
npm install
npm run validate
npm run build
npm run scaffold:city -- --adcode=320100
npm run dev
```

手工：标题双入口 → 34 省大厅 → 北京一局、上海一局、哈尔滨一局；大厅「抽 3 道 34 省简称题」能出题。

## 已知限制

- 地标仍是程序化低模剪影。
- 岭南骑楼 / 绿洲套件尚无对应 live 城（工厂先于标杆）。
- 哈尔滨用北方砖冷色 + `northeast_grid`，尚未单开「东北厚墙」套件文件。
- 邻省旅行、四大区域对照卡未做成独立玩法，只出现在题库与图鉴字段。
