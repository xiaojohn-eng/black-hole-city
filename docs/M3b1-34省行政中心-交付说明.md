# M3b1 34 省行政中心 · 交付说明

日期：2026-09-21  
对照：`docs/M3a3-七大区非省会×3-交付说明.md`、`docs/提升方向-多维评估报告.md`、PRD §10。  
原则：**省会/首府打穿，不是 333 完成，也不是 293 完成。** 工厂路径：`scaffold:city` + 套件 → `write-m3b1-packs.mjs` 补最低知识/测验。重庆只用江南水岸讲两江，禁止山城毁城秀默认皮肤。

## 本切片成功标准

- **34 个省级行政区各 ≥1 座行政中心 live**
  - 省：省会；自治区：首府；直辖市：主城包；特别行政区：教学包行政中心；台湾省：台北教学包
- M3a3 不回退：七大区各 ≥3 座非省会 live，全国非省会 live ≥21
- **不宣称 293 地级市已收录，更不宣称 333 已收录可玩**

本刀只做行政中心。其余地级仍是名录占位或既有非省会 live。

## 工厂路径

1. `npm run scaffold:city -- --adcode=<行政中心> --kit=<套件>` 导出 B 级草稿（本刀 20 座新建）。
2. `node tools/write-m3b1-packs.mjs` 把 5 座草稿（石家庄/长春/长沙/贵阳/乌鲁木齐）+ 20 座新城补知识/测验、GUARD/VISIT、气候/河海套件，升 live。
3. `npm run validate:m3b1` 断言 34 省各 ≥1 行政中心 live；失败即红。

## 质量下限（每座新/升 live）

- `city.json` / `layout.json` / `knowledge.json` / `quiz.json` 齐
- ≥1 GUARD + ≥1 VISIT；分区 ≥3；知识卡 ≥8；6–8 题 ≥4、9–12 题 ≥5（局后抽 3 题）
- 套件匹配气候/河海：贵阳改江南水岸（不再误用北方砖）；兰州用北方砖河谷，不套绿洲卡通；重庆只用江南水岸讲两江
- 允许 B 级套件剪影，不要求精模
- 台北：省级行政中心教学点，不用国名字体/首都符号；钓鱼岛、赤尾屿只在图鉴教学，3D 不标坐标
- 香港/澳门：省级特别行政区，不并入广东

## 灰壳规则（不变）

- 34 个省级卡片全部可点，且行政中心可进 3D。
- 省内其余地级：已有非省会 live 可进；未做城显示「记忆修复中」，**不可开 3D**。
- 不上未审中国全图。客户端禁止 `lat`/`lon`。
- 天安门级 GUARD、宗教/健康/校园 VISIT 继续生效。
- 大厅进度文案写「34 省行政中心可玩 / 非省会 live≥21 / 管线」，**不是 333 完成，也不是 293 完成**。

## 门禁

- 34 省各 ≥1 座行政中心 live（adcode 与 `data/admin_div.csv` 对齐）
