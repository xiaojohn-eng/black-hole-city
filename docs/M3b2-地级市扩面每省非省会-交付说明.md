# M3b2 地级市扩面 · 每省 ≥1 非省会 live · 交付说明

日期：2026-09-21  
对照：`docs/M3b1-34省行政中心-交付说明.md`、`docs/提升方向-多维评估报告.md`、PRD §10。  
原则：**凡有 `prefecture_city` 的省/自治区各 ≥1 座非行政中心地级市 live。这是 M3b 第一批扩面，不是 293 完成，更不是 333 完成。** 工厂路径：`scaffold:city` + 套件 → `write-m3b2-packs.mjs` 补最低知识/测验。选城按气候/河海多样性与课标常见城，禁止网红插队堆西南山城秀。

## 本切片成功标准

- 凡有 `prefecture_city` 的省/自治区，至少 1 座「非行政中心」地级市 live
  - 行政中心名单以 `tools/region7.mjs` 的 `M3B1_CAPITAL_PACKS` / `isProvincialCapital` 为准
  - 直辖市 / 港澳 / 台湾教学包不要求本刀再加非省会
- M3b1 不回退：34 省行政中心全部 live
- M3a3 不回退：七大区各 ≥3 座非省会 live，全国非省会 live ≥21
- **不宣称 293 地级市已收录，更不宣称 333 已收录可玩**

本刀新增/升 live **13** 座非省会地级市（12–20 的诚实上限内）。结束后 `prefecture_city` live **61/293**。其余地级仍是名录占位。

## 工厂路径

1. 从 CSV / `admin-div-data.mjs` 算出缺口省（M3b1 后仅省会 live、零非省会地级市的 13 个省/自治区）。
2. `npm run scaffold:city -- --adcode=<缺口城> --kit=<气候/河海套件>` 导出 B 级草稿（本刀 13 座）。
3. `node tools/write-m3b2-packs.mjs` 补知识/测验、GUARD/VISIT、气候/河海套件，升 live，更新 manifest。
4. `npm run validate:m3b2` 断言有地级市的省各 ≥1 非省会 live；失败即红。

## 质量下限（每座新 live）

- `city.json` / `layout.json` / `knowledge.json` / `quiz.json` 齐
- ≥1 GUARD + ≥1 VISIT；分区 ≥3；知识卡 ≥8；6–8 题 ≥4、9–12 题 ≥5（局后抽 3 题）
- 套件匹配气候/河海；允许 B 级套件剪影，不要求精模
- 日喀则/海东暂用北方砖剪影：高原石套件未进 0 号批次
- 包头不用毡房默认皮；曲靖/日喀则/三亚禁止山城毁城秀
- 三沙市保持 `playable_3d=false`

## 灰壳规则（不变）

- 34 个省级卡片全部可点，且行政中心可进 3D。
- 省内其余地级：已有非省会 live 可进；未做城显示「记忆修复中」，**不可开 3D**。
- 不上未审中国全图。客户端禁止 `lat`/`lon`。
- 天安门级 GUARD、宗教/健康/校园 VISIT 继续生效。
- 大厅进度文案写「34 省行政中心可玩 + 每省 ≥1 非省会地级市 / prefecture 约 61/293 / 管线」，**不是 333 完成，也不是 293 完成**。

## 门禁

`npm run validate:m3b2`：

- 有 `prefecture_city` 的省/自治区各 ≥1 座非省会 live（adcode 与 `data/admin_div.csv` 对齐）
- 本刀 13 座新 live 均在 `liveCityPacks`，且都不是行政中心
- `prefecture_city` live 在 60–292（诚实上限：本刀不是 293 完成）
- disclaimer 必须写 每省非省会地级市、约 61/293、不是 333、不是 293，并保留 34 省行政中心与非省会 ≥21
- 三沙不可玩；新包不得使用 `mountain_layers` 默认皮

`npm run validate:m3b1` 继续断言 34 省行政中心。  
`npm run validate:region7`（别名 `validate:m3a3`）继续断言七大区各 ≥3 非省会、全国 ≥21。失败即红。

`npm run validate` && `npm run build` 必须全绿。

## 明确不做

- 293 地级市 / 333 全量 live（后续 M3b3+ / M3c）
- 州/盟/地区 C 级（M3c）
- M4 家长账号/后端；家乡 GPS；未审底图
- 山城毁城秀默认皮肤；按网红度插队堆丽江/大理/张家界
