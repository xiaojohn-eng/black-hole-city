## 总评

### 现网：玩法内核已通，产品身份仍是「虚构街机」

仓库是一套可上 GitHub Pages 的 **3 分钟限时吞城**。双阈值、吸引圈、质量→半径→相机拉远、五分区网格、L1–L10、摇杆/键鼠、暂停结算、本地最高分，均已在 `src/game/` 跑通（README「玩法（对齐 PRD M1）」与 `SwallowSystem` / `Player` / `World` 一致）。

它**不是**中国城市产品的缩水版。证据：

| 现网事实 | 出处 |
| --- | --- |
| 唯一空间是虚构「星湾市·中央区」240×240 正交路网 | `README.md`；`World.ts` `MAP_SIZE = 240`；`UIManager.ts` 标题「v0.1 · 星湾市·中央区」 |
| 唯一主地标是程序化电视塔「星湾塔」 | `World.createMesh` 圆柱+观景舱+尖顶；结算文案「星湾塔已入洞」 |
| 无选城、无图鉴、无测验、无课标标签、无 `data/` | 仓库根目录无 `data/`、`packs/`、`tools/`；`storage.ts` 只有 `settings` / `profile` |
| 叙事词表是破坏向 | `constants.ts`：「拆房小队」「街区粉碎机」「终焉之洞」；`Game.ts` toast「破塔者」 |
| 物体是按层级染色的盒子/车块，无河、无轮廓、无民居地理 | `World.buildStaticCity` + `createMesh` |

一句话：现网验证了「地面黑洞手感」；完整版要验证的是「孩子能认出这是哪座中国城，并且学到课标点」。两件事不在同一层。

### 完整版 PRD：全国架构写全了，但还不能当施工图直接开工

`docs/PRD-黑洞吞噬中国城市完整版.md`（v1.0）把产品从街机改写成 **记忆博物馆 × 全国城市内容平台**：34 省大厅、333 地级一包、三学段题库、GUARD/VISIT/ECO、标准地图与未成年人原则、M0–M4、约 2000+ 人日产能模型。附录 E 的全国点名（含盟/州/地区/省直辖/三沙 N 类/台湾教学包）是这份 PRD 真正超过「网红城合集」的部分。

同时，PRD 仍有三类「看起来完整、执行会裂」的问题：

1. **14 座标杆城写在 Markdown 表里，不是可校验的 `city.json`**；`data/admin_div.csv` 在文档里是契约，仓库里不存在。  
2. **M1 一次塞进大厅 + 三座 S 级 + 知识卡 + 测验 + 图鉴 + 家乡选择器**（§10），以现网硬编码 `World` 的现状，6～8 周会做成三张换皮星湾。  
3. **内部口径未锁死**（题量 §4.4 vs 附录 C.3；直辖市 adcode §4.1 vs 附录 A.2；显示等级 10 档 vs 现网 9 档）。

### 最大风险（单一）：内容工业化尚未开始，却已用「全国完整版」定义成功

§3.1 验收句写得很硬：`playable_3d` 地级行未达 333/333，不得宣称全国收录。§9.7 估算内容约 **2000+ 人日**，且要求「先编辑器与 CSV 全表，再填包」。仓库现状是 **0 行 CSV、0 个内容包、0 个校验脚本、0 座可识别真城**。

若下一迭代按街机惯性「先把星湾做得更炫 / 先做一座山城展示片」，会同时踩中三个坑：家长看到的仍是毁城视频；教研无法对课标；333 城永远到不了 B/C 级。完整版的最大风险不是技术栈（Three.js 可延续），而是 **在数据管线成立之前用单城表现力冒充全国产品**。

### 1. 产品定位与叙事（记忆博物馆 vs 吞噬爽感）

#### 现状证据

现网卖点与完整版愿景不在同一句话里：

| 层 | 现网 | 完整版 |
| --- | --- | --- |
| 产品名 | 「黑洞吞噬城市」；副标「从汽车吃到摩天楼」 | 内部名「记忆黑洞 · 中国城市博物馆」（PRD 文首）；卖点「收回散落的城市记忆」（§1.2） |
| 玩家身份 | 未写；引导是「吃小的、变大、吃更大」 | 「记忆守护员」；吸入 = 归档（§1.3） |
| 失败 | 倒计时归零，「本局结束」 | 「裂隙未合拢，记忆暂存口袋」（§1.3） |
| 地标 | 「星湾塔已入洞！· 破塔者」（`Game.ts` `handleDigest`） | 全息入馆、地面留守护光斑；国家象征 **禁止吞噬**（§1.3、§2.2 `GUARD`） |

现网循环（`Game.ts` `updatePlay` → `endRound`）是：**移动 → 吞 → 加分 → 超时结算 → 再来**。没有博物馆、没有展品、没有「地面恢复」。镜头震动与吞噬旋转缩小（`SwallowSystem.updateSwallowing`）强化的是破坏快感。`index.html` description 仍是「从汽车吃到摩天楼」。

PRD 自己也承认这是冲突，并用词表替换作为 M0 强制项（§1.3、§10 M0：「标题画面不再写星湾市为唯一世界」）。

#### 缺口

1. **表层玩法与教育包装尚未设计「可被短视频看懂」的视觉差。** 只改文案不够：剪辑里仍是楼缩小进洞，观众读成 Hole.io。PRD 写了全息/光斑，现网零实现。  
2. **限时冲分（现网唯一模式）与生涯博物馆（完整版主模式）抢注意力。** §6.3 表已经拆开，代码只有限时。  
3. **商店名「吞噬」与课堂话术「归档」分裂。** 不先定发行渠道，两个名字会一起出现在家长群。  
4. 爽感来自「终于吃得动那栋楼」；教育来自「这栋楼为什么在这儿」。现网 toast 是「公寓区在西侧」「地标就在东北方向」（`Game.ts`），给的是 **地图攻略** 不是 **地理原因**。

#### 提升建议

- **先定一条不可谈判的演出语法（M0）：** 可吞物 = 记忆碎片化作光粒归档；GUARD = 环绕光环、庄重音、禁止滑稽；VISIT = 短推镜 + 知识卡；吞完地标地面留下光斑而非坑。现网吸入动画可留，但必须加「入库」层，否则词表是假的。  
- **双模式入口在标题页就拆开：** 「3 分钟冲分（训练场）」vs「收进博物馆（真城）」。星湾保留，但降级为虚构训练场（PRD §10 M1 已写，必须执行）。  
- **结算禁止「摧毁度」「破塔者」。** 改「本局入库件数 / 镇馆进度 / 裂隙稳定度」。限时高分可以留，但不要当生涯货币（§6.6 已规定 E 与分数分轨——尚未落地）。  
- **短视频防污名：** 水印「记忆已入库」；官方录屏只用北京 GUARD 或熊猫 eco，不用「塔被吞」当封面（呼应 §12.5 失败信号）。

#### 优先级与里程碑

**P0。** 叙事不过，后面所有真城都是高风险素材。  
**里程碑：M0 词表 + 演出语法冻结；M1 标题页双模式 + 至少 1 个 GUARD 可玩。**

### 2. 核心玩法与手感（双阈值、成长、城际差异）

#### 现状证据

双阈值是真的，不是设计文档空话：

```text
canSwallow = radius ≥ sizeThreshold × threshScale
         AND mass   ≥ massThreshold × threshScale
```

出处：`constants.ts` `canSwallow`；`SwallowSystem.update` 用其决定吸引 / 吞噬 / 碰撞挡路 + 锁图标。吸引圈 `ATTRACT_FACTOR = 1.35`，吞噬近圈 `SWALLOW_RADIUS_FACTOR = 0.35`，同时吞噬上限 8。质量公式 `radius = 0.6 × (mass/10)^0.42`，速度随 `log10(mass)` 下降并夹在 4.5～14（`speedFromMass`）。相机距离 `CAM_D0 + CAM_B × radius`（`CameraRig.ts`）。

成长档：`LEVEL_MASS` 9 档（10…4000），`LEVEL_LABELS` 1–9；`TIERS` 却是 L1–L10。显示等级到不了 PRD §2.3 的第 10 档「国家图鉴使」。

难度只乘阈值与质量奖励（`storage.ts` `difficultyMultipliers`：easy 0.9 / hard 1.1），**不改时长**——`durationHint` 算了但从未写入 `settings.duration`。

分区：`World.QUOTAS` 五区约 241 次生成 + 1 座强制地标，注释写「约 PRD 满配额 35–45%」；物体不刷新（与 README、PRD §6.2 限时默认一致）。`zoneAt()` 在 `constants.ts` 导出，**全项目无引用**，分区实际靠 `zoneBounds` 矩形。

#### 缺口（手感层，不是「再加点特效」）

**（1）双阈值在数值上几乎退化成「半径门槛」。**  
用现网公式反推：开局 `mass=10, radius=0.6`，L1 双过。L4 `sizeThreshold=1.9, massThreshold=70`，但 `radiusFromMass(70)≈1.36 < 1.9`，半径达标约需 mass≈156。L6 `size=4.5, massThr=260`，`radiusFromMass(260)≈2.36`，半径达标约需 mass≈1200。L10 `size=22, massThr=4000`，`radiusFromMass(4000)≈7.4`，半径达标约需 **mass 数万**。  
结论：`massThreshold` 在 L2 之后长期松弛，玩家感到的是「洞口不够大」，不是「质量不够」。PRD 仍把双阈值写成「手感宪法」（§6.1），但 **没有要求重标定**，完整版若沿用现网表，高阶地标在 180 秒内会变成极少数「破塔」局——与教育「每城都要摸到镇馆」冲突。

**（2）失败信息是二元锁，不是双阈值教学。**  
锁图标是 canvas 画的 🔒（`SwallowSystem.showLock`），不区分「差半径 / 差质量」。6–8 岁（§6.7）需要的是可读原因，不是符号。

**（3）城际差异目前为零。**  
同一套正交 40 单位路网、同一套灰绿地面（`groundMat 0x3d4a3a`）、同一套按 tier 染色的盒子。换城若只换 `colorPalette`，孩子分不出武汉和乌鲁木齐。PRD 附录 B 的变体库（冰面、坎儿井、骑楼、两江、多层地面）**一个都没接到 `World`**。`World.reset()` 只清可吞物再 `spawnObjects()`，**静态城市场景永不重建**——连切「另一张程序图」的运行时都没有。

**（4）成长不跨局、不跨城。**  
`Player.reset()` 每局回到 `M0`；`profile` 只存 `highScore / maxMass / gamesPlayed`（`storage.ts`）。PRD §2.3 要求生涯等级继承、单局半径不继承——数据结构不存在。

**（5）计分有两套加法，连击可能被结算式盖掉或留下。**  
局内：`(reward+5)×combo` + 地标 8000 + 首次吞地标时 `timeLeft×2`（`handleDigest`）。局末：`massGained + eaten×5 + 地标`，再 `score = max(局内, 局末)`（`endRound`）。`ResultSnapshot.perfect` **直接等于** `landmarkEaten`，与是否还有剩余时间无关。README 公式与代码不完全同一口径。

**（6）L9 显示名「终焉之洞」与 L10 物体脱节。** 教育产品不宜用「终焉」做儿童 HUD。

#### 提升建议

1. **重标定阈值表，使「双」字成立：** 在 L1–L6 让 mass 与 size 交替成为紧约束（例如部分民居 mass 紧、部分载具 size 紧），L7+ 仍可 size 偏紧，但 **生涯模式必须保证 12 分钟内能触达 L10 或 GUARD**（用本城入口质量、密度、不倒计时解决，而不是把 size=22 留在 180 秒局里）。阈值表升级为 `data/tiers.json`，难度只乘 `thresholdScale`（§2.2 已说，代码仍写死在 `constants.ts`）。  
2. **HUD 显示双条：** 「洞口 / 质量」分别对当前瞄准物，锁图标改成「再长大一点」+ 缺哪一项。这是双阈值可被感知的最小补丁。  
3. **把变体当城际差异的主通道，而不是贴图。** 每城 1–3 个附录 B ID；同省禁止全撞车（§9.5 已列入校验器，应在 M1 就跑一条：北京 `hutong_maze` + `axis_guard`）。没有变体的城 = 星湾换色。  
4. **切城 = 销毁并重建 `World`（或 `CityWorldFactory`），禁止在静态网格上刷另一城的物体。**  
5. **限时与生涯分表计分。** 修 `endRound` 口径；生涯用博物馆能量 E（§6.6）。  
6. 显示等级与物体层级脱钩的文档化：HUD 用 §2.3 称号；L10 是物体层；生涯 10 级用图鉴/测验星，不靠单局 mass。

#### 优先级与里程碑

**P0（阈值可感知 + World 可数据驱动）；P1（变体 3～5 个打样）；P2（协作一大一小，§6.4）。**  
**里程碑：M1 必须能在真城里打完一局双阈值，并让测试者说出「和训练场哪里不一样」（路网/河/变体至少一项）。**

### 3. 教育有效性与课标闭环

#### 现状证据

现网学习投放 = **零**。无知识卡、无测验、无错题本、无学段、无家长报告、无课堂模式。`Profile` 无图鉴字段。引导三步全是操作（`Game.tutorialText`）。

PRD 教育设计本身对齐 2022 课标的方式是对的，不是空贴标签：

- 地理课标主题五「认识中国」：34 省简称与行政中心、疆域与南海诸岛/钓鱼岛、地形气候河湖、长江黄河、民族共同体、秦岭—淮河、因地制宜（PRD §1.5；标签附录 C.2）。  
- 小学道德与法治：首都与国家象征、版图意识（`moral.primary.beijing` / `moral.primary.map`）。  
- 学段拆题：6–8 配对；9–12 课标主档；13+ 区域联系（§1.5.2、§7.3）。  
- 图鉴公式、口袋复习、家长周报「会讲的一句话」、教师一页纸对照课标（§7.1–7.6）——全是可教的结构。

课标原文要点（教育部 2022 年版，主题五）与 PRD 标签可对上：识别 34 省级并记简称与行政中心；说明南海诸岛是中国领土组成部分、钓鱼岛及其附属岛屿是中国固有领土；秦岭—淮河等界线。PRD 明确 **版图题只进 2D 图鉴/测验，3D 战场不输出坐标**（§1.5.2、§11.1）——这条必须保持。

#### 缺口

1. **「玩 3 分钟」与「学 12～18 分钟」是两个产品。** README / 标题页「一局约 3 分钟」；§2.5 单城学习节奏 12–18 分钟；课堂 15 分钟。现网只有前者。知识卡若插进 180 秒冲分，会被跳过；若不打断，等于没学。  
2. **题库一题都没有。** 附录 C 只有一道示例 `q-bj-01`（北京简称）。14 城「测验结构」是提纲（「6–8：首都、天安门…」），不能导入。§4.4 与附录 C.3 **最低题量不一致**（见第 9 维）。  
3. **解锁绑测验正确率 ≥60% 才能省内全开（§2.4.4）** 对课堂不友好：一节课失败会锁死邻市；对街机玩家则是惩罚阅读。需要「课堂模式关闭解锁闸」与「生涯模式软闸（建议下一城而非硬锁）」。  
4. **无前测/后测设计。** §12.2 有首测 vs 口袋复习目标，但没写每城锚题 ID、没写不要用同一道题当教学展示又当后测。  
5. **学段与操作难度正交（§7.5）现网未暴露。** 设置里只有 easy/normal/hard，没有「学习年龄」。近代史默认关（南京纪念馆 13+，§5.6）无从配置。  
6. **教师页、班级码、对照课标一页纸（§7.6）无信息架构。** 没有「本节对应 RCG02 / GEO41」如何展示的线框。  
7. **方言语音、名人「籍贯 vs 活动地」** 在标杆城散文里反复强调（詹天佑、孙中山、屈原、丹顶鹤勿误植扎龙），但没有题干审校清单模板，LLM 草稿会稳定踩雷。

#### 提升建议

- **学习闭环最小件（必须进 M1，不能等到 M4）：** 归档触发知识卡（每卡每局 ≤1 次，可「稍后再读」进局后汇总）→ 局后 3 题可跳过 → 错题进口袋 → 本城图鉴条目点亮。不要等家长账号。  
- **锚题制：** 每城 9–12 档设 5 道「不可跳过展示、但可跳过作答」的课标锚题（位置/简称/河或山/气候/职能择三），其余为扩展。全国公共题库承担 34 省简称与行政中心（附录 C.3 已要求），**禁止 333 城各写一遍「本省简称」**。  
- **解锁改建议而非硬锁：** 测验星影响「小博士」与推荐下一城；省内全开改生涯等级或任一门槛（§2.4.3 已有「等级 ≥3 或一次完美」——应用它，不要用 60% 正确率卡死孩子）。60% 仅用于 **三星** 与教研报表。  
- **课堂 15 分钟剧本写成关卡脚本：** 0–1 分鸟瞰「我们在哪」；1–10 分只开放起步+生活+一个 GUARD/VISIT；最后 3 分 3 题 + 集体点亮。限时模式不要进课堂默认。  
- **学段开关进设置并允许家长锁。** 与 easy/normal/hard 并排，文案写清「学习年龄 / 操作难度」。  
- **质性验收（§12.4）提前到 M1 小样本：** 孩子指本省、说一句山/河/气候/物产、家长破坏感 ≤2/5。没有这 20 组亲子，不要宣称教育有效。

#### 优先级与里程碑

**P0（知识卡 + 3 题 + 图鉴雏形 + 学段开关）；P1（口袋回流、教师一页纸、公共 34 省题库）；P2（家长周报 PDF、班级码）。**  
**里程碑：M1 北京包能指出「首都 / 京 / 中轴或胡同 / 温带季风」四选三；M2 34 省简称题 live。**

### 4. 全国内容架构与 333 城产能

#### 现状证据

PRD §3 已经把「完整版」定义成内容平台，而不是 14 个样例：

- 34 省级（23+5+4+2）、地级 **293 市 + 30 州 + 7 地区 + 3 盟 = 333**、省直辖单元、台湾省教学包、港澳特区、三沙 N 类（§3.1、§3.3、附录 E 计数表）。  
- 分级 S/A/B/C/D/N 决定 3D 预算，**不决定在不在名单里**（§3.4）。  
- 物理契约：`data/admin_div.csv`、`province_adj.json`、`cities/{adcode}/`（§3.6、附录 A）。  
- 产能：S 14×20 人日、A 20×10、B≈250×6、C 40×4、D 30×2 ≈ **2000+ 人日内容** + 编辑器 200 人日（§9.7）。  
- 明确禁令：禁止先做完重庆再讨论云南 8 州（§9.7）。

仓库：**没有 `data/`，没有 `admin_div.csv`，没有校验器 `validate:cities`，没有 `tools/city-editor`。** 14 城内容停在 §5 散文。

#### 缺口

1. **总表未机器化。** 各省全量点名在 Markdown 里，无法 CI。行政区划一旦变更（撤地设市），散文不会自己 diff。  
2. **标杆城不能当包用。** §5 有地标交互类型、变体 ID、3D 资源名，但缺强制字段里的 `zones[]` 多边形、`quotas`、`review` 签名、知识卡正文、quiz.json。从散文到 live 包，每座 S 级仍要 15–25 人日（§9.3），文档进度 ≠ 内容进度。  
3. **B 级 5～8 人日在没有套件/编辑器时是幻想。** 路网简化、三地标、20 题、四审，任何一项人工都会超支。长尾城（衡水、云浮、朔州、七台河…）会先被砍——然后产品又变成省会打卡，违反 §12.3「非省会局数 ≥40%」。  
4. **半自动边界（§9.4）未产品化。** 允许自动：气候带、邻省、人口量级、干线简化、干扰项、套件换色。禁止自动 live：民族、历史、版图、宗教、在世人物、商标。缺生成器提示词仓库与 diff 工具，LLM 会把禁止项写进 draft。  
5. **卫星与省直辖容易被忘。** 曲阜、敦煌、都江堰、坎儿井、神农架、济源、海南省直辖县市、新疆直辖县级市：PRD 写了形态，没有排期表。三沙若被做成「可吞岛礁」是合规事故。  
6. **邻接表用于解锁（§3.5）尚未存在**；琼粤隔海教学相邻等特例只在文字里。

#### 提升建议（产能是制作人问题，不是「多写几城」）

| 顺序 | 动作 | 目的 |
| --- | --- | --- |
| 1 | 民政公开名录 → `admin_div.csv` 全量行，`status=placeholder` 允许 | 让 333 成为门禁而不是口号 |

### 5. 单城辨识度与 3D / 美术 / 音频

#### 现状证据

视觉：Lambert 无阴影（`Game.initThree` `shadowMap.enabled = false`）、半球光+定向光、雾 `Fog(0x87b5d4, 90, 240)`、正交路网间距 40、五块分区染色、40 个灰色装饰盒、载具=盒子+驾驶舱、建筑=盒子+L7 以上一条窗带、地标=金黄电视塔（`World.ts`）。无水面、无等高、无桥、无轮廓剪影。

音频：WebAudio 程序和弦 C 大三 + 五度（`AudioEngine.startBgm` 每 2.4s），吞噬按 tier 升频。无采样、无分省音色、无方言。README 已承认「BGM 为程序和弦非完整曲目」。

PRD 辨识度标准其实很清楚：轮廓 + 干线 + 河湖相对位置 + 地标剪影（§0、§8.2、附录 D.1 黑影测试 5 人中 ≥3 人从 4 城选出）。附录 D.2 点名禁止「全国默认重庆崖线 + 灰绿地面（即现网星湾风）」——注意：现网**并没有做重庆地形**（无多层崖线、无两江），它是 **无身份的灰绿网格**；禁令针对的是「把星湾/山城当默认皮肤」，不是说现网已经是重庆关。

#### 缺口

1. **可识别性主通道（河、岸、桥、环线、山体剪影）全部缺席。** 中国城市课标记忆点大量是「江城 / 山城 / 港城 / 绿洲」，现网无法表达。  
2. **地标剪影测试必败。** 通用电视塔在国内过多城同构（含重庆、沈阳、天津等），不能当身份。  
3. **音频是全国同一条和弦，** 与 `bgmPalette`（京胡、冬不拉…）脱节；方言字段（§4.2）无资源位。  
4. **LOD / 实例化 / glb 管线不存在。** 约 240 个独立 Mesh，切城与 333 包不可想象。`particles` 设置有字段无实现。  
5. **色觉与分区纹理（§6.7）未做**，五区只靠色块。  
6. 标杆城 3D 资源名已起（如 `bj_tiananmen_guard`、`wh_huanghelou`），但无美术任务单（面数、贴图、doNot、交互类型）。

#### 提升建议

- **辨识度优先级：轮廓鸟瞰 > 一条河或岸 > 1 个剪影地标 > 民居套件 > 精细贴图。** 钱应花在「打开地图 3 秒能猜城」，不是玻璃反射。  
- **每城「三件套」强制：** （1）简化轮廓或功能地理骨架（湖环、两江、中轴、绿洲块、山岛层）；（2）≥1 条命名水系或山体，没有则用标志性地物（盐湖、草原天际）；（3）≥1 个通过黑影测试的地标。B 级可以只有 3 个地标，但 3 个都必须可认，而不是 3 个盒子。  
- **先做附录 D.2 十套全国套件**（北方砖、胡同、江南、骑楼、盆地吊脚、东北厚墙、绿洲平顶、高原石、毡房、海岛坡），再铺 333。重庆多层地面只进 `mountain_layers` 变体，**不得进默认工厂**。  
- **音频：程序音保留作回退；** 每套件 4～8 小节采样循环 + 归档「入库铃」。GUARD 用独立庄重音，禁止沿用吞噬升频。方言默认关，本地审听后才开（§11.4）。  
- **剪影测试写进包验收：** 5 名未玩过该关的测试者，4 选 1，≥3 正确，否则不得 `status=live`。

#### 优先级与里程碑

**P0（真城三件套 + 禁止星湾默认皮肤进工厂）；P1（十套件与地标 LOD0/1/2）；P2（分省采样、方言、水面反射可选）。**  
**里程碑：M1 北京黑影测试过关；训练场与真城在标题页视觉上可区分。**

### 6. 技术架构与性能 / 分包 / 地图管线（相对现网 TS + Three.js）

#### 现状证据

栈：Vite 6 + TypeScript + Three r186，DOM HUD，`localStorage` 前缀 `bhc:v1:`，Pages `base: '/black-hole-city/'`（`package.json`、`vite.config.ts`）。运行时对象：`Game` 持有单例 `World` / `Player` / `CameraRig` / `SwallowSystem`。空间哈希 cell=12，0.25s 全量 rebuild（`Game.updatePlay`）。无 glTF、无 `InstancedMesh`、无动态 `import()` 内容包、无 scene dispose 切城、无 worker、无测试脚本。

PRD §8 判断正确：**不重写吞噬手感，把 `World.buildStaticCity()` 换成 `layout.json` + 皮肤。** 预算（§8.4）：壳 <3MB，S 城 <8MB，B 城 <2MB，进关 ≤8s，中档 30fps，iOS Safari 峰值警示 400MB。地图：国界只用标准地图；OSM 仅城内干线且 ODbL 署名；客户端无经纬度（§8.2、§11.1）。

#### 缺口

1. **`World` 是不可复用的关卡。** 静态网格在构造时建一次；`reset()` 不重建环境。完整版 `CityWorldFactory`（§8.5）从零开始。  
2. **没有内容加载器、manifest、版本号。** 333 包若仍打进主 bundle，Pages 会炸。  
3. **性能基线未测。** 画质只改 `setPixelRatio`（1/1.5/2），低档并不减物体、不换 impostor。雾远平面 240 = 整张图，帮不上 LOD。  
4. **切城泄漏风险：** `SwallowSystem.lockSprites`、物体 geometry 在 `World.reset` 里只处理 `objects`，静态路网材质常驻；未来多次 `new World` 必须有显式 dispose，PRD 未写。  
5. **地图管线工具链未选品：** Mapshaper / 简化公差 / OSM 提取批次号只在 §8.2 流程里。审图号方案是 M0 交付物，尚未有「用哪一家标准地图服务、大厅是真图嵌出还是卡片列表」的决策。  
6. **OSM ODbL share-alike** 与闭源商业发行的冲突，§11.6 只写「遵守」，没有法务结论（衍生路网是否必须开源）。这会卡住 App 上架。  
7. **存档升级 `bhc:v2:`**（图鉴、防沉迷时钟）未设计迁移。`resetAllData` 会删从未写入的 `unlocked` 键。  
8. **无障碍：** 摇杆已有；色觉纹理无；闪光建议 ≤3Hz（倒计时 `pulse 0.6s` ≈1.67Hz，目前安全）；无「关闭吸引动画」。

#### 提升建议

- **运行时拆三层：** （1）壳：大厅、吞噬系统、HUD；（2）全国索引 JSON（精简自 CSV）；（3）`packs/{adcode}/` 异步加载。吞噬系统保持现接口：`canSwallow(player, eatable)`。  
- **M1 就可以不嵌标准地图：** 大厅用 **34 张省级卡片 + 搜索**（简称、别称），底图用「已审示意图」或先不上中国全图，避免审图阻塞垂直切片。真图进 M2。这是技术/合规联合决策，应写入 ADR。  
- **性能：填充建筑 InstancedMesh；地标独立 glTF；吞噬中物体出实例进对象池**（§8.3 已写，需变成任务）。低档：降密度、关雾外装饰、地标 LOD2。  
- **`World.dispose()` + 切城集成测试** 列为 M1 技术验收，PRD 目前没有。  
- **坐标：编辑器内部可用相对格网；导出剥 `lat/lon`。** CI 扫客户端包（§9.5）。  
- **法务先行选路网策略：** 自绘干线 / 购买可商用数据 / OSM 并开源衍生。未决前不要把 OSM 几何打进 live 包。

#### 优先级与里程碑

**P0（World 数据驱动 + 包加载 + dispose + 客户端无经纬度门禁）；P1（实例化、LOD、分包 CDN）；P2（后端、WebView 壳）。**  
**里程碑：M1 训练场与北京为两个 pack；切来切去内存不线性涨；低档 30fps。**

### 7. 合规、未成年人、商标与版图表述

#### 现状证据

现网：虚构地名「星湾」，无中国全图，无真人、无品牌 IP，无付费、无账号、无 UGC。未成年人风险主要是 **破坏隐喻 + 倒计时压迫 + 镜头震动**（可关）。尚不触发地图审核（没有中国地图）。

PRD §11 原则质量高：标准地图与台湾按省、港澳不并入广东、三沙非吞噬、GUARD 名单、无抽卡、家乡仅本地、不输出争议坐标。标杆城已有可执行禁令（世界之窗/迪士尼/赌场/冰雪大世界商标、台北不用首都符号、宗教 VISIT）。

#### 缺口

1. **发行形态未定性 → 义务未知。** 网页演示、教辅电子、网络游戏（含小游戏）的版号、实名防沉迷、「830」时段、地图审核触发条件不同。§11.2 只说「法务定性，不因教育自我豁免」，没有决策记录。  
2. **现网词表与录屏在完整版真城出现后会立刻违法规意图。** 「破塔者」「粉碎」+ 真实「东方明珠」是事故组合。必须在第一座真城 **之前** 换词表与结算。  
3. **GUARD 名单、宗教 VISIT 名单、商标黑名单** 只在散文里，没有 `data/compliance/*.json`，CI 无法检查 §9.5「该城若有国家象征则必须 guard」。  
4. **大厅一旦出现中国全图，审图就是 P0。** 漏岛、错色、把香港画进广东、台湾设色错误，都是下架级（§11.1、§12.5）。  
5. **肖像与集体卡** 有原则，无「在世人物默认拒绝」的字段级校验。  
6. **防沉迷时钟** 在 M4，但若 M1 就上小游戏商店，M1 就必须接。应把「商店发行」设为独立开关。  
7. 倒计时最后 10 秒 `playWarn` + HUD `danger` 闪烁：频率目前可接受，但完整版不要加更密闪光。

- **M0 产出三张名单数据：** `guard_national.json`、`visit_religion_health_school.json`、`trademark_blocklist.json`（迪士尼、世界之窗、冰雪大世界、连锁餐饮品牌等）。

- **真城包四审签名位（§4.4 `review`）进 CI：** 缺合规签名不得 live。  
- **家长破坏感作为发行门禁**（§12.4 ≤2/5），与功能验收并列。  
- 台湾包、港澳包、三沙馆 **单独合规 checklist**，不要混进普通 B 级城流程。

#### 优先级与里程碑

**P0（词表、GUARD、发行形态 ADR、禁止未审全图）；P1（名单数据化与四审 CI）；P2（实名防沉迷，仅当网游发行）。**  
**里程碑：第一座真城 live 之前，破坏向称号清零；无标准地图则大厅不用中国全图。**

### 8. 商业 / 发行 / 增长（若做成产品）

#### 现状证据

现网：免费 Pages 试玩，无账号、无内购、无分析、无渠道包。许可证「仅供试玩与演示」（`README.md`）。成功指标 §12 给了 D1/D7、时长上限、家乡完成率、训练场占比、测验正确率——**代码零埋点**。

产能 2000+ 人日内容 + 工程，PRD 同时规定 **默认无充值、无抽卡、无随机付费**（§11.2）。这是明确的商业模型空洞：教育公益口径与全国内容成本未接通。

#### 缺口

1. **没有收入假设，却有 333 城义务。** 完整版要么找到买单方，要么缩小「完整」的公开承诺（例如「省级可玩 + 地级图鉴」分两年）。  
2. **渠道未选：** Web / 微信或抖音小游戏 / App / 课堂平板，决定包体、防沉迷、支付、审图。  
3. **增长点其实清楚但没写成系统：** 家乡置顶、剪影可识别、亲子录屏、34 省收集欲。现网没有任何「分享我的城」。  
4. **训练场占比指标（§12.1 ≤20%）** 在只有训练场时无意义；真城弱于星湾手感时，用户会逃回训练场——需要真城手感不低于星湾。  
5. **B2B 课堂** 需要班级码当天失效、不强制校外实名（§7.6），与 C 端留存活动冲突。  
6. 竞品心智是 Hole.io「毁城」；教育渠道会拒，娱乐渠道会嫌说教。需要 **双商店文案**，不是一条副标打天下。

#### 提升建议

- **先定产品形态再定 333 承诺：**  
  - 形态 A：开源/演示（现状延伸）→ 公开只保证「大厅 34 省 + 标杆城」，333 作为长期库。  
  - 形态 B：教辅/教研合作 → 课标覆盖与教师页优先，3D 只做 S/A。  
  - 形态 C：C 端小游戏 → 必须解决变现（广告对低龄不合适）与版号，不建议作为完整版主路径。  
- **增长机制只做三种：** 家乡星、亲子「会讲的一句话」卡片分享、暑期七大区护照（§6.5）。不做毁城排行榜（§8.6）。  
- **埋点最小集（本地匿名）：** 城 ID、学段、是否跳过测验、GUARD 完成、训练场 vs 真城、暂停次数。不上儿童个人信息。

## 建议的下一迭代：只做一个 M1 垂直切片
