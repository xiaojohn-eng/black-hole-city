# M3b12 地级市扩面 · 每省 ≥11 非省会 live · 交付说明

日期：2026-09-25  
对照：`docs/M3b11-地级市扩面每省非省会×10-交付说明.md`、`docs/提升方向-多维评估报告.md`、PRD §10。  
原则：**凡「非省会 prefecture_city 总数 ≥11」的省/自治区，至少 11 座非行政中心地级市 live。这是 M3b 第十一批扩面，不是 293 完成，更不是 333 完成。** 工厂路径：`scaffold:city` + 套件 → `write-m3b12-packs.mjs` 补最低知识/测验。选城按气候/河海多样性与课标常见城，禁止网红插队堆张家界/大理/黄山/泰山/伊春等山城秀。

## 本切片成功标准

- 凡非省会 `prefecture_city` ≥11 的省/自治区，至少 11 座「非行政中心」地级市 live
  - 行政中心名单以 `tools/region7.mjs` 的 `M3B1_CAPITAL_PACKS` / `isProvincialCapital` 为准
  - 直辖市 / 港澳 / 台湾教学包不要求本刀再加非省会
  - 青海（非省会仅海东 1 座）本刀继续豁免到 ≥11
  - 海南：三沙永不可玩，可玩非省会仅三亚+儋州=2，故按「非省会总数 <11」豁免到 ≥11；勿动三沙
  - 新疆（非省会仅 3 座）无法到 11 → 本刀豁免到 ≥11，但须保持 ≥3
  - 宁夏（非省会仅 4 座）无法到 11 → 本刀豁免到 ≥11，但须保持 ≥4
  - 贵州、西藏（非省会各 5 座）无法到 11 → 本刀豁免到 ≥11，但须保持 ≥5
  - 吉林、云南（非省会各 7 座，已全 live）无法到 11 → 本刀豁免到 ≥11，但须保持 ≥7
  - 内蒙古、福建（非省会各 8 座，已全 live）无法到 11 → 本刀豁免到 ≥11，但须保持 ≥8
  - 陕西（非省会仅 9 座，已全 live）无法到 11 → 本刀豁免到 ≥11，但须保持 ≥9（铜川仍在）
  - 河北、山西、浙江、江西（非省会各 10 座，已全 live）无法到 11 → 本刀豁免到 ≥11，但须保持 ≥10
  - **黑龙江**：非省会 eligible 11、live 10，唯一剩余是伊春（山城秀禁选）→ 本刀豁免到 ≥11，保持 ≥10，**不选伊春**
- M3b11 不回退：非省会 ≥10 的省各 ≥10 座非省会 live（豁免青海、海南、新疆、宁夏、贵州、西藏、吉林、云南、内蒙古、福建、陕西与非省会总数 <10 的省）
- M3b10 … M3b1 / M3a3 均不回退
- **不宣称 293 地级市已收录，更不宣称 333 已收录可玩**

本刀新增/升 live **11** 座非省会地级市（诚实上限 15）。结束后 `prefecture_city` live **257/293**。其余地级仍是名录占位。缺口省（M3b11 后仅 10 座非省会 live、且非省会总数 ≥11、且除禁选外仍有可选城）各补 1 座，实测辽苏皖鲁豫鄂湘粤桂川甘。上一刀座数上限 250 放宽为仍禁止 ≥293，否则本刀 257 座会把 `validate:m3b11` 打红；≥10 地板不回退。

## 工厂路径

1. 从 CSV / `admin-div-data.mjs` 算出缺口省（M3b11 后仅 10 座非省会 live、且可玩非省会 prefecture_city ≥11、且除禁选外仍有可选城的 11 个省；青海、海南、新疆、宁夏、贵州、西藏、吉林、云南、内蒙古、福建、陕西、河北、山西、浙江、江西、黑龙江不在缺口内）。
2. `npm run scaffold:city -- --adcode=<缺口城> --kit=<气候/河海套件>` 导出 B 级草稿（本刀 11 座）。
3. `node tools/write-m3b12-packs.mjs` 补知识/测验、GUARD/VISIT、气候/河海套件，升 live，更新 manifest。
4. `npm run validate:m3b12` 断言非省会 ≥11 的省各 ≥11 非省会 live；失败即红。

选城理由（河海多样性，不按网红度）：

- 抚顺不选辽阳/本溪：太子河已在鞍山，本溪水洞不插队。浑河上游和沈阳城区是同一条河的两段。
- 镇江不选常州：苏南运河和太湖已够。京口是运河过长江的南岸，北岸是扬州。
- 池州不选淮南/马鞍山/铜陵：淮河、长江干流都讲过。秋浦河是入江的另一条河。黄山仍灰壳，九华山不进本课。
- 滨州不选枣庄/威海/聊城/泰安：泰安是泰山。德州已经讲运河和徒骇河，青岛和日照已经讲海。滨州补黄河入海之前的一段。
- 鹤壁不选平顶山/三门峡/焦作：沙河、黄河、沁河容易重复或靠山。淇河汇入卫河，和洹河、卫河分成三课。
- 荆门：湖北非省会只剩这一座可选。漳河，不把汉江或长江再讲一遍。
- 怀化不选张家界：沅江中游，常德讲入洞庭。张家界仍灰壳。
- 茂名不选东莞/中山/惠州：东江在河源，韩江在汕头，西江在肇庆，北江在韶关，漠阳江在阳江。鉴江独自入南海。
- 贺州不选防城港/河池：北部湾和柳江上游都更容易重复。贺江流出广西再汇入西江。
- 巴中不选广元/雅安/内江/达州：嘉陵江、青衣江、沱江、渠江都已有课。巴河是渠江的支流。不拿光雾山。
- 金昌：甘肃非省会只剩这一座。金川河进入石羊河水系，武威认石羊河干流绿洲。用绿洲平顶，不拿祁连山。

青海豁免。海南豁免到 ≥11（三沙不可玩）。新疆豁免到 ≥11（非省会仅 3 座，已 live ≥3）。宁夏豁免到 ≥11（非省会仅 4 座，已 live ≥4）。贵州、西藏豁免到 ≥11（非省会各 5 座，已 live ≥5）。吉林、云南豁免到 ≥11（非省会各 7 座且已全 live，保持 ≥7）。内蒙古、福建豁免到 ≥11（非省会各 8 座且已全 live，保持 ≥8）。陕西豁免到 ≥11（非省会仅 9 座且已全 live，保持 ≥9，铜川仍在）。河北、山西、浙江、江西豁免到 ≥11（非省会各 10 座且已全 live，保持 ≥10）。黑龙江豁免到 ≥11（eligible 11，live 保持 10，伊春不选）。

## 质量下限（每座新 live）

- `city.json` / `layout.json` / `knowledge.json` / `quiz.json` 齐
- ≥1 GUARD + ≥1 VISIT；分区 ≥3；知识卡 ≥8；6–8 题 ≥4、9–12 题 ≥5（局后抽 3 题）
- 套件匹配气候/河海；允许 B 级套件剪影，不要求精模
- 金昌用绿洲平顶；池州/怀化/巴中禁止山城毁城秀
- 三沙市保持 `playable_3d=false`，不可拿来充数

## 灰壳规则（不变）

- 34 个省级卡片全部可点，且行政中心可进 3D。
- 省内其余地级：已 live 可进；未做城显示「记忆修复中」，**不可开 3D**。
- 不上未审中国全图。客户端禁止 `lat`/`lon`。
- 天安门级 GUARD、宗教/健康/校园 VISIT 继续生效。
- 大厅进度文案写「34 省行政中心可玩 + 有地级市的省非省会 ≥11/省（豁免青海、海南、新疆、宁夏、贵州、西藏、吉林、云南、内蒙古、福建、陕西、河北、山西、浙江、江西、黑龙江与非省会总数 <11 的省）/ prefecture 约 257/293 / 管线」，**不是 333 完成，也不是 293 完成。**

## 已知限制

- 地标仍是程序化低模剪影。
- 湖北、甘肃本刀只剩一座可补的非省会，所以荆门、金昌是诚实上限，不是网红插队。
- 抚顺和沈阳都认浑河：沈阳是城区，抚顺是上游。辽阳仍是灰壳。
- 池州课只认秋浦河。九华山在池州境内，但不做山城秀，黄山仍是另一座灰壳城。
- 金昌和武威都连着石羊河水系：武威认干流绿洲，金昌只认金川河。
- **本切片是 M3b 第十一批，不是 293 完成，更不是 333 完成。**
