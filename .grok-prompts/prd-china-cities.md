你是资深儿童向 3D 教育游戏制作人 + 玩法设计师 + 中国地理教研顾问。

## 背景
仓库 black-hole-city 现有 MVP：虚构「星湾市」地面 3D 黑洞吞噬玩法（Vite+TS+Three.js）。用户不满「只有个别城市/重庆感」——要的是**完整版全国城市**产品。

## 任务
深度研究并产出一份**超级完整、可直接指导研发**的游戏 PRD，写入：
`docs/PRD-黑洞吞噬中国城市完整版.md`

必须用简体中文。不要只写重庆；不要只写几个样例敷衍。要覆盖「中国各个城市」的产品结构。

## 产品定位
- 超炫酷 **3D**「黑洞吞噬城市」——城市地面主题（非太空）
- 地图基于**中国真实城市地理轮廓/路网/地标布局的可识别简化**（教育向，非测绘精度）
- 各地**特色剧情 + 独特玩法变体**
- 核心受众：孩子；边玩边学：**地理、地标、名人、城市特点、区域气候/物产/文化符号**
- 通过「吞噬」机制做正向学习闭环（收集知识卡、解锁图鉴、测验/挑战，避免宣扬破坏真实城市——叙事可包装为「清理异常引力 / 守护城市记忆 / 黑洞博物馆」等儿童友好设定，需在 PRD 里定调）

## PRD 必须包含的章节
1. 愿景与一句话卖点、目标用户、学习目标（地理课标对齐到小学/初中可落地层级）
2. 核心循环（Core Loop）与成长曲线（黑洞等级 ↔ 可吞噬物层级 ↔ 城市解锁）
3. 全国结构：省/自治区/直辖市/特别行政区 → 地级市/州/盟 的**完整内容架构**
   - 给出「全国城市内容总表」的组织方式：至少列出全部省级单位，并说明每个省下地级市如何纳入（可用附录 CSV/表格结构；在文档内给出完整省级清单 + 每个省代表性地级市清单，并规定「全量地级市数据」的字段与导入流水线，使产品定义为覆盖全国所有地级行政区）
4. 单城内容模板（强制字段）：位置/气候带/地形、人口量级、著名建筑≥5、名人≥3、物产/美食、方言/文化符号、特色剧情节拍、玩法变体、学习测验题库结构、3D 地标清单
5. 至少 **12 个标杆城市** 写满模板样例（覆盖华北/东北/华东/华中/华南/西南/西北 + 港澳台各至少一城）：北京、上海、广州、深圳、杭州、南京、武汉、成都、重庆、西安、哈尔滨、乌鲁木齐，并加香港或澳门、台北（若版权/政治表述敏感，用「繁体中文教学向城市包」中性表述并遵守合规）
6. 玩法系统：双阈值吞噬、分区地图、限时/生涯模式、多人/协作可选、季节活动
7. 教育系统：图鉴、知识卡、家长报告、难度与年龄段（6-8 / 9-12 / 13+）
8. 技术架构：延续 Three.js；真实地图数据源建议（OSM/官方公开边界简化）、LOD、性能、移动端
9. 内容生产管线：如何规模化生成「全国所有地级市」内容（编辑器、校验、审核、版本）
10. 里程碑：M0 叙事定调 → M1 全国选城大厅+3城 → M2 省级解锁 → M3 全量地级市内容包 → M4 学习报告与运营
11. 风险与合规：真实地名商标、未成年人、破坏隐喻、地图国界与南海诸岛等表述规范（只给原则，不输出争议地图坐标）
12. 成功指标（留存、知识测验正确率、城市图鉴完成度）
